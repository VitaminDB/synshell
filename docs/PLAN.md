## 1. Что это

Головоломка 8×8: внизу три фигуры, их перетаскивают на поле, полные ряды
и колонки схлопываются. Поворота нет (как в жанре) — вместо него каталог
всех ориентаций. Партия заканчивается, когда ни одна из оставшихся фигур
никуда не ставится.

Чем лучше оригинала:

* **Честная раздача** (`game/generator.rs`): тройка принимается, только если
  существует порядок и позиции, при которых все три фигуры встают (поиск с
  учётом схлопывания линий, `all_placeable`); проиграть можно только
  ошибившись. Крупные фигуры реже на полном поле; три одинаковые не выпадают.
  Когда на поле ≤ 26 кубиков, с шансом 40 % раздача подбирается «под
  идеальную очистку» (`can_clear_all`): существуют ходы, собирающие всё поле.
* **Превью очистки**: пока фигура над полем, подсвечиваются ряды/колонки,
  которые она закроет; «магнитное» прилипание к ближайшей клетке.
* **Погашенные фигуры**: фигура, которой некуда встать, рисуется тусклой.
* **Живая картинка**: кубики со скошенными гранями и стеклянным бликом
  (полигоны через `CanvasContext`), блик-волна по полю раз в 7 с,
  вдавливание при установке, вспышка и схлопывание линий с частицами,
  встряска поля, ударные волны и вспышки экрана на комбо ×3+, «огненный»
  режим (искры от счётчика комбо, золотое свечение поля), конфетти на
  идеальной очистке и комбо ×5, волна-«подпрыгивание» кубиков от очищенной
  линии, шлейф за перетаскиваемой фигурой, всплывающие «+120», баннеры
  «КЛАСС! / ОТЛИЧНО! / ВЕЛИКОЛЕПНО! / ИДЕАЛЬНО! / НОВЫЙ РЕКОРД!».
* **Очки**: 10/клетка; линии `100·n + 50·n·(n−1)` × комбо; комбо прощает
  два хода без очистки; идеальная очистка поля +300.
* **Клавиатура**: `1/2/3`/`Tab` — выбрать фигуру, стрелки — курсор,
  `Enter`/`Space` — поставить, `N` — новая партия, `Esc` — меню.
* **Тач** (Android): фигура поднимается выше пальца.
* **Рекорд и статистика** сохраняются (`persist.rs`, `stats.txt`).
* **Адаптивная раскладка**: от 340×600 до широких окон (`ui/layout.rs`).
* **Материалы фигур** (`game/piece.rs::Material`): иногда фигура выпадает
  деревянной (9 %), хрустальной (6 %), лавовой (4 %) или золотой (3 %) — все
  её кубики рисуются в этом материале (`ui/cube.rs::draw_material`), при
  очистке дают бонус за клетку (5/15/20/30), свои частицы (щепки, осколки,
  монеты, угли), подпись «ЗОЛОТО ×5 +150» и звук. Материал хранится в старшем
  нибле клетки (`make_cell/cell_color/cell_material`).
* **Уровни сложности** (`rules.rs::Difficulty`, выбор в меню, действует на
  новую партию): легко — мелкие фигуры чаще, комбо прощает 3 хода; норма —
  как описано; сложно — крупные чаще, гарантируется лишь одна размещаемая
  фигура (как в оригинале), комбо прощает 1 ход. Рекорды раздельные
  (`Stats::best_by`), в HUD метка сложности под рекордом.
* **Способности за энергию линий** (`rules.rs::Ability`, панель под треем,
  клавиши Q/W/E): +1 энергии за линию (до 12); Обмен (3) меняет тройку,
  Молот (4) убирает кубик, Бомба (7) — область 3×3 с ударной волной. Молот и
  бомба ждут цель на поле (подсветка, Esc — отмена).
* **Пять фоновых треков** YuE2 (`audio::TRACKS`, 22.05 кГц моно, ~2.8 МБ
  каждый), переключение ‹ › в меню с плавным кроссфейдом, выбор сохраняется;
  кнопка ∞ — режим «по кругу»: после конца трека микшер сам переходит к
  следующему (`audio::current_track()` синхронизирует подпись в меню).
* **Интерфейс на русском** (баннеры, меню, экран конца игры).
* **Звук** (`src/audio.rs`): собственный микшер поверх потокового
  `AudioPlayer` syngui — фоновая музыка в бесшовном цикле + эффекты с
  «лестницей» высоты по комбо; переключатели «Звуки/Музыка» в меню
  сохраняются. Эффекты синтезированы `tools/gen_sfx.py` (numpy), музыка —
  YuE2 через `synaptix song` (см. `assets/music/*.log`).
* **Android-сборка**: `./run-phone.sh` собирает APK (arm64-v8a) и ставит на
  телефон по USB; каталог `android/` — gradle-проект с GameActivity.

## 2. Структура

```
src/
├── main.rs            fn main → elle_block::run_desktop()
├── lib.rs             App-билдер (desktop + android_main), GameCtx
├── anim.rs            easing, damp, частицы, всплывающие подписи
├── persist.rs         Stats: load/save (XDG_DATA_HOME / ELLE_BLOCK_DATA), настройки звука
├── audio.rs           Sfx, микшер (поток), init/play/play_pitched/set_music/suspend
assets/sfx/*.wav       эффекты 48 кГц (tools/gen_sfx.py)
assets/music/bgm.wav   фоновый трек 24 кГц моно (вшивается include_bytes!)
├── game/              чистая модель, без UI (юнит-тесты внутри)
│   ├── rng.rs         xorshift64*, weighted()
│   ├── piece.rs       Shape (const fn), Family (вес, цвет), Catalog 41 ориентация
│   ├── board.rs       Board 8×8, can_place/place/clear_full_lines/preview_lines
│   ├── generator.rs   deal(): честная тройка под текущее поле
│   └── rules.rs       Scoring, Gain, Game::place → Placement
└── ui/
    ├── mod.rs         GameView/View: ввод (мышь/тач/клавиши), drag, тик анимаций
    ├── layout.rs      Geo: колонка, HUD, поле, трей (всё из bounds)
    ├── theme.rs       палитра, шрифт, глифы Material Icons
    ├── cube.rs        draw_cube (4 грани + глянец), draw_piece
    ├── fx.rs          Pop/Vanish/LineFlash/Banner/Return, длительности
    ├── overlay.rs     геометрия карточек меню и Game Over (общая для paint и hit-test)
    └── paint.rs       весь кадр: фон, HUD, поле, трей, частицы, оверлеи
tests/play_flow.rs     TestHarness: drag, snap, возврат, клавиатура, добор, меню, game over
```

Принципы:

* Модель — в `GameCtx::game: RwSignal<Game>` (её видят тесты); элемент
  хранит только презентационное состояние (`Fx`, `Drag`, `KbCursor`).
* Один элемент рисует всё через `DisplayList`; MSS не используется.
* Геометрия считается одной функцией `layout::compute(bounds)` и
  используется и для отрисовки, и для хит-тестов, и в тестах.
* `needs_repaint()` всегда `true` → элемент в реестре анимаций, `animate`
  вызывается каждый кадр (фон «живёт»).

## 3. Команды

```bash
cargo test                 # модель + интеграционные тесты (без GPU)
cargo run                  # окно 460×820
ELLE_BLOCK_DATA=/tmp/x cargo run   # отдельный файл статистики
ELLE_DEMO=drag|over|menu|board|clear cargo run # демо-состояния (clear — ход с очисткой через 3.6 с)
./run-phone.sh             # APK → телефон (см. memory.md G24)
python3 tools/gen_sfx.py   # пересинтезировать эффекты
synaptix song "instrumental, no vocals, ..." --lyrics "" --cot off --models ~/Storage/syn_models \
    -o assets/music/yue_x.wav --max-tokens 1600   # 25 токенов = 1 с; --cot off = без вокала
timeout 120 synaptix transcribe ~/Storage/syn_models/whisper-large-v3-turbo.syn yue_x.wav  # пусто = нет слов
ffmpeg -i yue_x.wav -af loudnorm=I=-19:TP=-2:LRA=9 -ac 1 -ar 22050 -sample_fmt s16 assets/music/trackN.wav
```

Скриншот из скрипта — см. рецепт в `memory.md` (timeout + spectacle).
