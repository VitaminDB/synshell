# Пароли (`synpass`)

Менеджер паролей synshell для компьютера и телефона: записи (название,
логин, пароль, сайт, заметки, избранное) под одним мастер-паролем.

## Что умеет

- **Копировать** — крупные кнопки «Копировать пароль» / «Логин» на карточке
  записи и кнопки копирования прямо в строке списка. Пароль копируется с
  пометкой секрета (`x-kde-passwordManagerHint`) и через 30 с стирается из
  буфера (15 с … не стирать — в настройках), если его не заменили.
- **Общий буфер через synlink** — скопированное сразу вставляется на
  соединённом телефоне или компьютере (`[link] clipboard`, см. `LINK.md`);
  очистка секрета доходит и туда.
- **Просмотр** — показать пароль в карточке (моноширинно) или крупно: каждый
  символ в своей клетке с номером, заглавные, цифры и символы разными цветами,
  группы по четыре — удобно переписывать с экрана.
- **Генератор** — длина 8…64, заглавные, цифры, символы, «без похожих»
  (0/O, 1/l/I); новая запись сразу получает сгенерированный пароль.
  Полоска силы пароля в редакторе и карточке.
- Поиск, «Избранное», «Недавние» (по последнему копированию).
- **Секретный вопрос** — забытый мастер-пароль не теряет записи: на экране
  входа «Забыли мастер-пароль?» → ответ на вопрос → новый мастер-пароль.
  Вопрос задаётся при создании хранилища (по желанию) или в настройках
  (готовые вопросы или свой; нужен мастер-пароль); там же его можно убрать.
  Ответ сравнивается без учёта регистра, лишних пробелов и «ё». В настройках
  мастер-пароль меняется по текущему паролю или по ответу.
- Автоблокировка без действий (5 мин по умолчанию), Ctrl+L — заблокировать,
  Ctrl+N — новая запись, Esc — назад.
- Телефон — стек «список → запись → редактор» с жестом «назад»; компьютер —
  две колонки.

## Хранилище

`~/.local/share/synpass/vault.json` (`SYNPASS_VAULT` — другой путь, для
проверок), права 0600. Записи (JSON) зашифрованы XChaCha20-Poly1305 случайным
ключом хранилища; сам ключ лежит в «обёртках» — зашифрован ключом из
мастер-пароля и, если задан секретный вопрос, ключом из ответа (Argon2id,
64 МиБ, 3 прохода, своя соль у каждой). Вопрос хранится открыто — его видно
на экране входа. Смена пароля или вопроса перешифровывает только обёртку.

Ответ на вопрос — второй ключ к хранилищу и обычно слабее пароля: выбирайте
то, чего не узнать из соцсетей, или свой вопрос. Без вопроса забытый
мастер-пароль не восстановить.

Настройки — `~/.config/synshell/passwords.toml`: `autolock_min` (0 — не
блокировать), `clear_secs` (0 — не стирать), `[generator]`.

## Синхронизация

Через файлы устройств synlink (`$XDG_RUNTIME_DIR/synlink/<устройство>`,
не смонтированы — приложение просит демон смонтировать): хранилище там лежит
по тому же пути в домашнем каталоге. Пока хранилище открыто, оно сливается со
всеми соединёнными устройствами при открытии, после каждой правки, при
соединении устройства и раз в 30 с:

- слияние по записям: у каждой постоянный id и время изменения, побеждает
  более позднее; удалённая запись остаётся «надгробием» без данных, чтобы
  удаление дошло до всех;
- итог записывается и туда — так копия на телефоне обновляется, даже когда
  «Пароли» там закрыты; открытые «Пароли» замечают изменение файла и
  вливают его;
- на устройстве нет хранилища — туда копируется своё; при первом запуске
  на новом устройстве можно взять хранилище с соединённого («или возьмите
  хранилище с устройства») — нужен его мастер-пароль;
- у копий одного хранилища общий ключ; две независимо созданные копии с
  одним мастер-паролем сходятся к ключу с меньшим `key_id`; другой
  мастер-пароль — в шапке «другой мастер-пароль», синхронизации нет;
- сменили мастер-пароль или вопрос на одном устройстве — обёртки новее
  (`meta_modified`) расходятся на остальные, а открытые там «Пароли»
  подхватывают их без повторного ввода (ключ хранилища тот же).
