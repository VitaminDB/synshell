# Игровой режим (gameshell)

Третий режим оболочки рядом с рабочим столом и телефоном: полноэкранный лаунчер игр в духе
игровой консоли или Steam Big Picture. Все приложения в режиме — во весь экран без рамок и
заголовков, диалоги — по центру поверх; управление геймпадом, клавиатурой, мышью и касаниями.

## Включить и выйти

Режим меняется на лету, без перезапуска сеанса:

| Откуда | Как |
|---|---|
| Клавиши | **Super+G** — игровой режим и обратно (`form-factor toggle-game`) |
| Рабочий стол | меню питания → «Игровой режим» |
| Телефон | шторка → плитка «Игровой режим» |
| Параметры | «Игровой режим» → «Режим оболочки сейчас» |
| Игровой режим | Guide / Super → «Выйти из игрового режима» |
| Терминал | `synwm msg form-factor game` (`desktop`, `phone`, `device`, `toggle-game`; без аргумента — текущий) |
| Конфиг | `[platform] form_factor = "game"` — сеанс начинается в игровом режиме; правка переключает и текущий |

Куда ведёт выход — `[gameshell] exit_to`: `device` (режим устройства: телефон для встроенной
DSI-панели, иначе рабочий стол), `previous` (откуда пришли), `desktop`, `phone`.
`remember_mode = true` — переключение действием записывается в `[platform] form_factor`.

## Что делает композитор

`synwm` различает **режим устройства** (по мониторам или `[platform]`; от него масштаб экрана и
кнопка питания) и **режим оболочки** (рабочий стол, телефон, игровой — меняется на лету). При
смене режима:

- политика конфига пересчитывается: в игровом — раскладка monocle, без рамок и зазоров,
  оболочка `[gameshell] shell` (по умолчанию `syngame-shell`);
- оболочка перезапускается своей командой;
- в игровом режиме корневые окна (xdg без родителя; X11 без `WM_TRANSIENT_FOR`, обычного типа и
  не фиксированного размера) становятся полноэкранными и не выходят из этого состояния по
  просьбе клиента; диалоги плавают по центру. `fullscreen_exclude` — app_id-исключения;
- при выходе из игрового режима окна, развёрнутые им, становятся просто развёрнутыми (в рабочую
  область под панелями);
- окна без фокуса: клавиатура уходит главному экрану оболочки (слой `syngame-home`), поэтому
  стрелки и Enter работают в лаунчере сразу после закрытия игры;
- жесты от краёв экрана (`[gestures]`) работают и в игровом режиме: снизу вверх — быстрое меню.

IPC: `Request::FormFactor` → `Response::FormFactor { current, device, previous }`, действие
`Action::FormFactor(FormFactorTarget)`.

## Лаунчер (syngame-shell)

- **Главная**: афиша выбранной игры (логотип, «Играть», избранное, действия; фон — размытая
  афиша), полки «Запущено», «Недавние», «Избранное», «Все игры».
- **Запущенные** (видна, пока есть окна): плитка приложения с кнопками «Закрыть» (если оно не
  закрылось за 1,5 с — само спрашивает, его окно показывается) и «Убить» (SIGKILL); то же — X →
  «Закрыть» / «Убить (SIGKILL)» на любой запущенной игре.
- **Игры**, **Избранное**, **Steam**, **Android** (приложения syndroid, видна, если они есть),
  **Приложения** (программы Linux), свои подборки `tag:<метка>` — сетки плиток.
  Состав и порядок — `tabs`, вкладка при запуске — `start_tab`.
- Плитка — обложка 2:3 (Steam `library_600x900`/`library_capsule`, своя `cover`), без обложки —
  значок на цветном градиенте с именем; звезда у избранных; заставка запуска до появления окна.
- **Быстрое меню** (кнопка ☰ слева от вкладок, Guide, Super, M/Start на главной, свайп от нижнего края): продолжить, на главную,
  закрыть игру (повторное нажатие — подтверждение), запущенные, громкость и яркость (←/→),
  экранная клавиатура, параметры, выход из режима, питание. Пока оно открыто, геймпады
  захвачены (`EVIOCGRAB`) — нажатия не уходят в игру.
- Строка состояния (`status`): сеть, батарея, громкость, геймпад, часы. Подсказки кнопок внизу —
  под геймпад или клавиатуру, смотря чем пользовались последним.

### Управление

| Геймпад | Клавиатура | Действие |
|---|---|---|
| Крестовина, левый стик | Стрелки | выбор (удержание — повтор) |
| A | Enter, Пробел | играть / продолжить |
| B | Esc, Backspace | назад: к началу вкладки, затем к стартовой |
| X | X, Menu | действия с игрой (играть, избранное, закрыть, скрыть) |
| Y | F | избранное |
| LB / RB | Q / E, Tab, PageUp/PageDown | вкладки |
| Start | M, F1 | меню |
| Guide (или Select+Start) | Super | быстрое меню поверх игры (`guide_button`: `overlay`, `home`, `none`) |

Мышь и касание: наведение выделяет, щелчок или тап запускает, правая кнопка — действия.

Геймпады читаются напрямую из `/dev/input/event*` (кнопки `BTN_SOUTH`… `BTN_MODE`, крестовина
кнопками или `ABS_HAT0`, стик `ABS_X/Y`), подключение на лету; свой экранный контроллер
`syngamepad` для навигации пропускается. На телефоне и планшете оболочка запускает экранную
клавиатуру и контроллер, как мобильная.

## Библиотека

| Источник | Настройки |
|---|---|
| .desktop с категориями `game_categories` (по умолчанию `Game`) | `desktop_games`, `include_apps` |
| Steam: `appmanifest_*.acf` во всех библиотеках `libraryfolders.vdf`, картинки из `appcache/librarycache` | `steam`, `steam_dirs`, `steam_launch`, `steam_hide_tools` |
| Свои ярлыки `[[gameshell.game]]` | — |
| Все приложения Linux (вкладка «Приложения») | — |
| Приложения Android (syndroid, вкладка «Android») | — |

Ярлыки .desktop, запускающие `steam://rungameid/N`, сливаются с игрой Steam. Окно запущенной
игры узнаётся по `steam_app_<id>` (Steam), `app_id` (свои) или по .desktop. Спрятать игру —
X → «Скрыть из библиотеки» (пишет `hide`).

Избранное и время последнего запуска — `~/.local/state/synshell/gameshell.json`.

```toml
[[gameshell.game]]
name = "Pony Town"
command = "firefox --kiosk https://pony.town"
cover = "~/Картинки/pony-cover.png"   # 2:3
hero = "~/Картинки/pony-hero.jpg"     # широкая афиша
logo = "~/Картинки/pony-logo.png"
tags = ["web"]                        # вкладка tag:web (добавьте её в tabs)
app_id = "firefox"                    # чтобы «Играть» поднимало уже открытое окно

# Правка найденной игры: id Steam или .desktop.
[[gameshell.game]]
id = "steam:3105440"
name = "Heroes: Olden Era"
cover = "~/Картинки/heroes.png"
```

## Вид

`tile_size` (`small`, `medium`, `large`), `tile_style` (`cover`, `icon`), `hero`, `background`
(`hero`, `wallpaper`, `color`), `background_color`, `accent` (пусто — акцент темы), `hints`,
`panels` (обычные панели `[[panel]]` и в игровом режиме). Свои стили —
`~/.config/synshell/game.mss` поверх встроенных `crates/syngame-shell/styles/game.mss` (классы
`gs-*`, переменные `--gs-bg`, `--gs-fg`, `--gs-card`…).

## Код

| Где | Что |
|---|---|
| `synshell-common/src/config.rs` | `FormFactor::Game`, `[gameshell]`, `[[gameshell.game]]`, `apply_game_mode` |
| `synshell-common/src/action.rs` | `Action::FormFactor`, `FormFactorTarget` |
| `synwm/src/wm/game.rs` | политика окон, слой главного экрана, `set_form_factor` на лету |
| `syngame-shell/src/library.rs`, `steam.rs` | библиотека, Steam без клиента |
| `syngame-shell/src/nav.rs` | состояние, вкладки и разделы, навигация, запуск |
| `syngame-shell/src/home.rs`, `tiles.rs` | главный экран, плитки, афиша |
| `syngame-shell/src/overlay.rs` | быстрое меню (слой Overlay) |
| `syngame-shell/src/gamepad.rs` | геймпады через evdev |
| `synsettings/src/pages/game.rs` | Параметры → «Игровой режим» |

Прокрутка к выделенной плитке — `syngui::widgets::reveal_named` (все прокрутки над элементом,
вложенные ленты тоже).
