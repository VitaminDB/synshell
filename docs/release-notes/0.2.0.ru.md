# synshell 0.2.0 — первый публичный выпуск

synshell — окружение рабочего стола для Wayland на Rust, для компьютеров и телефонов. Устроено оно
как KDE Plasma: композитор `synwm` (на [smithay](https://github.com/Smithay/smithay)), отдельный
процесс оболочки с панелями, доком, меню запуска и уведомлениями и «Параметры системы». Все окна и
панели нарисованы на моём собственном GUI-фреймворке [syngui](https://github.com/VitaminDB/syngui).
Почти всё настраивается в одном файле, `~/.config/synshell/config.toml`, и применяется на лету.
Интерфейс переведён на 14 языков.

## Что внутри

**Рабочий стол и композитор.** Рабочие столы; раскладки «плавающая», «мозаика», «колонки», «сетка» и
«монокль»; прилипание к краям, обзор окон, Alt+Tab, правила окон, Xwayland, сокет IPC с JSON и
`synwm msg`. Док в духе macOS и Latte Dock, адаптивная панель, панель вместо заголовка развёрнутого
окна с глобальным меню (Qt/KDE и GTK 3), 14 встроенных тем, которые передаются в GTK, Qt/KDE и GIMP,
экран блокировки (PAM), свой портал показа экрана и снимков через PipeWire, снимки экрана `synshot`.
Если оболочка упадёт, композитор перезапустит её, а окна останутся на месте.

**Телефон.** Тот же композитор с оболочкой телефона (`synmobile-shell`), экранная клавиатура и
телефонные приложения: [Телефон](https://github.com/VitaminDB/synshell/blob/master/crates/syn-phone/README.ru.md),
[Сообщения](https://github.com/VitaminDB/synshell/blob/master/crates/syn-sms/README.ru.md),
[Камера](https://github.com/VitaminDB/synshell/blob/master/crates/syn-camera/README.ru.md),
[NFC](https://github.com/VitaminDB/synshell/blob/master/crates/syn-nfc/README.ru.md),
[Компас](https://github.com/VitaminDB/synshell/blob/master/crates/syn-compass/README.ru.md),
[Спорт и здоровье](https://github.com/VitaminDB/synshell/blob/master/crates/syn-health/README.ru.md),
[ИК-пульт](https://github.com/VitaminDB/synshell/blob/master/crates/syn-remote/README.ru.md).

**Приложения.** [Параметры системы](https://github.com/VitaminDB/synshell/blob/master/crates/syn-settings/README.ru.md),
[Проводник](https://github.com/VitaminDB/synshell/blob/master/crates/syn-files/README.ru.md) (архивы как папки, сетевые расположения, телефоны),
[Терминал](https://github.com/VitaminDB/synshell/blob/master/crates/syn-terminal/README.ru.md),
[Программы](https://github.com/VitaminDB/synshell/blob/master/crates/syn-pkg/README.ru.md) (репозитории Arch и AUR),

[Пароли](https://github.com/VitaminDB/synshell/blob/master/crates/syn-pass/README.ru.md),

Полный список со снимками — в [README](https://github.com/VitaminDB/synshell/blob/master/README.ru.md#приложения).

**Нейросети (synaptix).** Пакет `synaptix` — это служба synaptixd: языковые модели, речь, картинки
и видео для всех приложений на видеокарте NVIDIA, нейропроцессоре Intel или процессоре, один пакет
для любого устройства. На ней работают [Ассистент](https://github.com/VitaminDB/synshell/blob/master/crates/syn-assistant/README.ru.md)
(`synshell-ai`) — чат и голосовой разговор с локальными моделями, которые умеют управлять системой,
файлами, заметками и искать в интернете, — и нейрофильтры видеоплеера.

**Компьютер ↔ телефон.** `synlink` связывает устройства synshell по USB и Wi-Fi (QUIC с закреплёнными
ключами): сопряжение, экран и удалённый ввод ([Экран устройства](https://github.com/VitaminDB/synshell/blob/master/crates/syn-link-view/README.ru.md)),
файлы через FUSE, уведомления, общий буфер обмена, `ssh phone` без знания адресов, командная строка
и MCP-сервер для Claude Code. Пароли синхронизируются между связанными устройствами.

**Игры, Wine, Android.** Игровой режим (Super+G): полноэкранное меню в духе приставки с библиотекой
Steam, обложками, управлением с геймпада и быстрым меню прямо в игре.
[Компоненты Wine](https://github.com/VitaminDB/synshell/blob/master/crates/syn-wine-helper/README.ru.md)
ставят DLL, которых нет в самом Wine (MFC, рантаймы Visual Basic, OpenAL), один раз для всех префиксов.
[syndroid](https://github.com/VitaminDB/synshell/blob/master/crates/syn-droid/README.ru.md) запускает
Android-приложения в контейнере LineageOS (образы Waydroid) со своим рантаймом — каждое в своём окне.

## Установка

**Arch Linux (AUR)**, x86_64 и aarch64 — каждый пакет в двух видах: `-bin` (готовые бинарники из
этого выпуска) и `-git` (сборка из репозитория):

```sh
yay -S synshell-bin          # рабочий стол и все приложения, без нейросетей
yay -S synshell-core-bin     # минимум: композитор, оболочка, параметры, проводник, терминал
yay -S syn-vm-bin            # или любое отдельное приложение по имени пакета
```

Оболочка телефона — `synshell-mobile`, нейросети — `synaptix` и `synshell-ai`. Затем выберите
«synshell» в своём диспетчере входа; если его нет, включите встроенный экран входа:
`systemctl enable synlogin.service`.

**Архивы** в этом выпуске: `.tar.zst` для каждого пакета под x86_64 и aarch64, суммы — в `SHA256SUMS`.

**Мобильные приложения:** APK [«Бросить курить»](https://github.com/VitaminDB/synshell/blob/master/crates/syn-quitsmoke/README.ru.md)
(`syn-quitsmoke`) и [Syn Blocks](https://github.com/VitaminDB/synshell/blob/master/crates/syn-blocks/README.ru.md)
(`syn-blocks`) для Android 11 и новее (arm64) — скачайте на телефоне и откройте, чтобы установить;
неподписанный IPA [«Цикла»](https://github.com/VitaminDB/synshell/blob/master/crates/syn-woman-cycle/README.ru.md)
(`syn-woman-cycle`) для iPhone — его нужно подписать своим Apple ID.

Сборка из исходников — в разделе [«Сборка и запуск»](https://github.com/VitaminDB/synshell/blob/master/README.ru.md#сборка-и-запуск).

## Известные ограничения

- **Ранняя стадия.** Один разработчик, первый коммит — сентябрь 2026 года. Шероховатости неизбежны,
  ключи конфигурации ещё могут меняться.
- **Проверено на одной машине.** synshell — мой повседневный сеанс на Arch Linux на гибридном ноутбуке
  (встроенная графика Intel Arrow Lake, панель 2560×1600 240 Гц с масштабом 1.4×, плюс NVIDIA RTX 5090
  Laptop). Несколько видеокарт, подключение мониторов на ходу и другие дистрибутивы в коде
  предусмотрены, но не проверялись.
- **Телефонная сборка** (aarch64) работает на Xiaomi 12T Pro; на других телефонах её не пробовали.
- Документация в `docs/` — на русском; README — на английском и русском.
