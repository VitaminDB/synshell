# Проводник (`syndesktop-files`)

Файловый менеджер syndesktop. Внешне — как Проводник Windows 11 (вкладки в
заголовке окна, адресная строка с хлебными крошками, командная панель, панель
навигации), по возможностям — на уровне Dolphin и дальше.

```
syndesktop-files [ПУТЬ|file://URI…]      # папки во вкладках; путь к файлу — его папка с выделенным файлом
syndesktop-files --view icons --split ~   # вид и две панели при запуске
```

Без аргументов открываются вкладки прошлого сеанса
(`~/.local/state/syndesktop/files-session.toml`, `[files] restore_tabs`).

## Возможности

- **Вкладки** в заголовке окна (своя рамка, кнопки окна как у композитора):
  Ctrl+T, Ctrl+W, Ctrl+Tab, средняя кнопка по вкладке — закрыть, по папке — открыть во вкладке.
- **Две панели** (F3): у каждой своя история, выделение и вид; активная обведена.
  Перетаскивание между панелями, вкладками и на боковую панель.
- **Виды**: значки (32–256 px, Ctrl+колесо/Ctrl± для размера), плитка, список, таблица
  с сортировкой по щелчку на заголовке колонки. Имена сокращаются в середине
  (`очень-длинн…ое.pdf`), расширение видно всегда.
- **Выделение** как в Проводнике: щелчок, Ctrl, Shift, рамка по пустому месту
  (с Ctrl — добавить), стрелки с учётом сетки, Home/End/PgUp/PgDn, Shift+стрелки,
  Ctrl+Пробел, Ctrl+A, Ctrl+Shift+I — обратить, поиск по первым буквам имени.
- **Миниатюры** картинок (с EXIF-поворотом) и видео (ffmpegthumbnailer или ffmpeg) в общем
  кэше `~/.cache/thumbnails` по спецификации freedesktop — их видят и другие программы.
- **Операции в фоне**: копирование, перемещение, ссылки, корзина, удаление — карточки
  в углу окна с прогрессом, скоростью, оставшимся временем, паузой и отменой.
  Совпадение имён — вопрос «Заменить / Оставить оба / Пропустить» (для папок —
  «Объединить»), «для всех». Вставка в ту же папку — `имя (1).txt`.
- **Отмена** (Ctrl+Z) копирования, перемещения, переименования, создания и удаления
  в корзину; кнопка «Отменить» в сообщении после удаления.
- **Корзина** по спецификации freedesktop: домашняя и корзины разделов
  (`.Trash-$UID`), «Откуда удалено» и дата удаления, восстановление, очистка.
- **Буфер обмена** совместим с GNOME и KDE: `text/uri-list`,
  `x-special/gnome-copied-files`, `application/x-kde-cutselection` — файлы
  копируются и вырезаются между проводником, Dolphin, Nautilus, браузерами.
  Вырезанные файлы приглушены до вставки.
- **Перетаскивание**: Ctrl — копировать, Shift — переместить, Alt — ссылка; без
  клавиш — перемещение в пределах раздела и копирование между разделами. На
  «Корзину» в боковой панели — удалить.
- **Поиск**: ввод в поле поиска сразу фильтрует текущую папку; Enter — поиск
  по имени во всех вложенных папках (сначала ближние результаты, шаблоны `*.rs`,
  несколько слов). Колонка «Папка» показывает, где найдено.
- **Открытие файлов** программой по умолчанию (`mimeapps.list` + `MimeType=` из
  .desktop, с учётом родительских типов shared-mime-info), «Открыть с помощью»
  с поиском и «всегда открывать этой программой», запуск .desktop и исполняемых ELF.
- **Панель навигации**: домашние папки XDG, закреплённые (`[files] pinned`,
  «Закрепить на панели» в меню папки), корзина, корень, съёмные и сетевые диски
  (в т.ч. смонтированные gvfs) с занятым местом.
- **Свойства**: тип, программа по умолчанию, размер папок (считается в фоне),
  даты, владелец, права, «Разрешить запуск как программы».
- **Создать**: папку (сразу с переименованием, как в Проводнике), текстовый
  документ, пустой файл, шаблоны из `~/Templates`.
- Слежение за папками (inotify): изменения снаружи появляются сразу.
- Тема — из `[appearance]` рабочего стола (палитра, акцент, скругления), тема
  оформления может добавить `files.mss`.

## Клавиши

| Клавиши | Действие |
|---|---|
| Enter / двойной щелчок | Открыть |
| Alt+← / Alt+→ / Backspace | Назад / вперёд |
| Alt+↑ | Вверх |
| Alt+Home | Домашняя папка |
| Ctrl+L, Alt+D, F4 | Ввести путь |
| Ctrl+F | Поиск |
| F2 | Переименовать |
| Delete / Shift+Delete | В корзину / удалить навсегда |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / вырезать / вставить |
| Ctrl+Shift+C | Копировать путь |
| Ctrl+Z | Отменить |
| Ctrl+Shift+N | Новая папка |
| Ctrl+H | Скрытые файлы |
| Ctrl+1 … Ctrl+4 | Значки / плитка / список / таблица |
| Ctrl+= / Ctrl+- | Крупнее / мельче |
| F3 | Две панели |
| Shift+F4 | Терминал в папке |
| F5 | Обновить |
| F9 | Панель навигации |
| Alt+Enter | Свойства |
| Ctrl+T / Ctrl+W / Ctrl+Tab | Вкладки |
| Ctrl+N | Новое окно |

## Настройки (`[files]` в config.toml)

```toml
[files]
view = "details"               # details | list | tiles | icons
icon_size = 64                 # значки в виде icons, px
sort_by = "name"               # name | modified | type | size
sort_descending = false
folders_first = true
show_hidden = false
single_click = false
confirm_trash = false          # спрашивать перед удалением в корзину
preview_pane = false
thumbnails = true
thumbnail_max_mb = 64
pinned = ["~/Projects"]
restore_tabs = true
```

Вид, сортировка, скрытые файлы и закреплённые папки сохраняются сами, когда их
меняют в окне. Программа для папок по умолчанию — `[general] file_manager`
(Super+E) и `MimeType=inode/directory` в `syndesktop-files.desktop`.

## Устройство

| Модуль | Что делает |
|---|---|
| `syngui::data::ItemView` | виртуализированная сетка/строки фиксированного размера: выделение, рамка, клавиатура, поиск по буквам, перенос, автопрокрутка (в syngui — пригодится не только проводнику) |
| `model.rs` | записи каталога, естественная сортировка, форматы размеров и дат |
| `state.rs` | вкладки и панели на сигналах, загрузка папок в фоне с метками (ответ старой загрузки отбрасывается), inotify, тема, сеанс |
| `actions.rs` | команды, меню, сочетания клавиш |
| `ops.rs` | задания в фоне, конфликты имён, журнал отмены |
| `trash.rs` | корзина freedesktop |
| `thumbs.rs` | пул миниатюр, кэш freedesktop |
| `search.rs` | поиск по имени в ширину |
| `places.rs` | места боковой панели, диски, gvfs |
| `syndesktop_common::mime` | shared-mime-info (globs2, magic, subclasses), описания, значки, `mimeapps.list` |
| `syndesktop_common::xdg` | .desktop (с `MimeType=`, подстановкой `%f/%F/%u/%U`), темы значков |

Проверка без экрана — снимок с шагами сценария:

```
syndesktop-files --screenshot out.png --size 1280x800 --view tiles \
    --script 'key:end;key:f2' ~/Документы
```

Шаги: `key:ctrl+a`, `click:x,y`, `rclick:x,y`, `dclick:x,y`, `mclick:x,y`,
`move:x,y`, `drag:x1,y1,x2,y2`, `release:x,y`, `type:текст`, `wait:мс`.
