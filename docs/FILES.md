# Проводник (`synfiles`)

Файловый менеджер synshell. Внешне — как Проводник Windows 11 (вкладки в
заголовке окна, адресная строка с хлебными крошками, командная панель, панель
навигации), по возможностям — на уровне Dolphin и дальше.

```
synfiles [ПУТЬ|file://URI…]      # папки во вкладках; путь к файлу — его папка с выделенным файлом
synfiles --view icons --split ~   # вид и две панели при запуске
```

Без аргументов открываются вкладки прошлого сеанса
(`~/.local/state/synshell/files-session.toml`, `[files] restore_tabs`).

## Возможности

- **Вкладки** в заголовке окна (своя рамка, кнопки окна как у композитора):
  Ctrl+T, Ctrl+W, Ctrl+Tab, средняя кнопка по вкладке — закрыть, по папке — открыть во вкладке.
- **Две панели** (F3): у каждой своя история, выделение и вид; активная обведена.
  Перетаскивание между панелями, вкладками и на боковую панель.
- **Виды**: значки (32–256 px: ползунок масштаба в строке состояния, Ctrl+колесо,
  Ctrl±), плитка, список, таблица
  с сортировкой по щелчку на заголовке колонки. Имена сокращаются в середине
  (`очень-длинн…ое.pdf`), расширение видно всегда.
- **Выделение** как в Проводнике: щелчок, Ctrl, Shift, рамка по пустому месту
  (с Ctrl — добавить), стрелки с учётом сетки, Home/End/PgUp/PgDn, Shift+стрелки,
  Ctrl+Пробел, Ctrl+A, Ctrl+Shift+I — обратить, поиск по первым буквам имени.
- **Миниатюры** картинок (с EXIF-поворотом) и видео (ffmpegthumbnailer или ffmpeg) в общем
  кэше `~/.cache/thumbnails` по спецификации freedesktop — их видят и другие программы.
- **Операции в фоне**: копирование, перемещение, ссылки, корзина, удаление — карточки
  в углу окна с прогрессом, скоростью, оставшимся временем, паузой и отменой.
  Совпадение имён — вопрос «Заменить / Оставить оба / Пропустить» (для папок —
  «Объединить»), «для всех». Вставка в ту же папку — `имя (1).txt`.
- **Отмена** (Ctrl+Z) копирования, перемещения, переименования, создания и удаления
  в корзину; кнопка «Отменить» в сообщении после удаления.
- **Корзина** по спецификации freedesktop: домашняя и корзины разделов
  (`.Trash-$UID`), «Откуда удалено» и дата удаления, восстановление, очистка.
- **Буфер обмена** совместим с GNOME и KDE: `text/uri-list`,
  `x-special/gnome-copied-files`, `application/x-kde-cutselection` — файлы
  копируются и вырезаются между проводником, Dolphin, Nautilus, браузерами.
  Вырезанные файлы приглушены до вставки.
- **Перетаскивание**: Ctrl — копировать, Shift — переместить, Alt — ссылка; без
  клавиш — перемещение в пределах раздела и копирование между разделами. На
  «Корзину» в боковой панели — удалить.
- **Поиск**: ввод в поле поиска сразу фильтрует текущую папку; Enter — поиск
  по имени во всех вложенных папках (сначала ближние результаты, шаблоны `*.rs`,
  несколько слов). Колонка «Папка» показывает, где найдено.
- **Просмотрщик картинок** (`synfiles --viewer ФАЙЛ`, «Просмотр
  изображений» в меню программ) — картинки из проводника открываются в нём. Сцена
  из просмотрщика вложений synthos: размытая копия картинки вместо пустых полей,
  масштаб к курсору колесом, перетаскивание, полосы прокрутки, двойной щелчок —
  вписать ↔ 1:1, стрелки листания и лента миниатюр всех картинок папки, панель
  (масштаб, вписать, 1:1, заполнить, поворот, отражение, во весь экран). Поворот
  по EXIF; HEIC/HEIF/AVIF (libheif), TIFF, JPEG XL и RAW (imagemagick)
  преобразуются в фоне в `~/.cache/synshell/viewer` (неоткрываемое 30 дней
  удаляется), соседние картинки готовятся заранее. В заголовке — размер,
  номер в папке, «Сведения» (I), «Показать в папке», «Открыть с помощью»,
  «Копировать», «Удалить» (в корзину, дальше — следующая).
  Клавиши: ←/→, PgUp/PgDn, Пробел, Home/End — листать (у приближенной ←/→
  двигают картинку), ↑/↓ — двигать, + / − — масштаб, 0 — вписать, 1 — 1:1,
  2 — заполнить, R / Shift+R — поворот, H / V — отражение, F или F11 — во весь
  экран, I — сведения, Delete — в корзину, Ctrl+C — копировать, Esc — выйти
  из полноэкранного режима или закрыть.
- **Открытие файлов** программой по умолчанию (`mimeapps.list` + `MimeType=` из
  .desktop, с учётом родительских типов shared-mime-info), «Открыть с помощью»
  с поиском и «всегда открывать этой программой», запуск .desktop и исполняемых ELF.
- **Панель навигации**: домашние папки XDG, закреплённые (`[files] pinned`,
  «Закрепить на панели» в меню папки), корзина, корень, съёмные и сетевые диски
  (в т.ч. смонтированные gvfs) с занятым местом.
- **Устройства** (`synshell_common::drives`): флешки и разделы дисков (udisks2),
  телефоны по MTP, iPhone и камеры (мониторы gvfs, нужен `gvfs-mtp` /
  `gvfs-gphoto2` / `gvfs-afc`). Несмонтированное — строкой «нажмите, чтобы
  открыть»: щелчок монтирует (телефон — `gio mount`, его надо разблокировать и
  выбрать «Передача файлов») и открывает. Смонтированный телефон — с именем и
  значком, в крошках и вкладке — «SAMSUNG Android › …», а не путь в
  `/run/user/UID/gvfs`. «Безопасно извлечь» отключает телефон или выключает диск.
  Подключили устройство — оболочка показывает уведомление «Открыть /
  Смонтировать» (`synshell-ui/src/devices.rs`), после монтирования — «Открыть /
  Извлечь»; вынули — уведомление убирается.
- **Свойства**: тип, программа по умолчанию, размер папок (считается в фоне),
  даты, владелец, права, «Разрешить запуск как программы».
- **Создать**: папку (сразу с переименованием, как в Проводнике), текстовый
  документ, пустой файл, шаблоны из `~/Templates`.
- Слежение за папками (inotify): изменения снаружи появляются сразу.
- Тема — из `[appearance]` рабочего стола (палитра, акцент, скругления), тема
  оформления может добавить `files.mss`.

## Раскладки: десктоп и телефон

Раскладка выбирается по ширине окна (`NARROW_BELOW` = 720 логических px,
`state::is_phone()`), окно при пересечении порога пересобирается целиком —
вкладки, история и выделение живут в состоянии и сохраняются.

- **Десктоп** — как в Проводнике Windows 11. Окно поуже подстраивается: колонки
  таблицы уходят по ширине панели (сначала «Тип»/«Откуда», потом дата — половина
  окна при двух панелях тоже считается), у «Сортировки» и «Вида» остаются только
  значки (< 900 px), поле поиска короче (< 1000 px).
- **Телефон** (`ui/phone.rs`): своего заголовка с кнопками окна нет — окно просит
  у композитора системную рамку (`syngui::signal::set_decorations`), на десктопе
  снова рисует свою с вкладками. Верхняя панель — меню мест, имя папки, поиск,
  «Вид и сортировка», «⋮»; под ней путь крошками и число элементов. Одна панель
  (разделение не показывается), виды — список (крупные строки: миниатюра, имя,
  размер/число элементов и дата) или сетка на всю ширину. Касания: тап открывает,
  удержание выделяет (режим выбора — верхняя панель «Выбрано: N», отметки у
  элементов, внизу «Копировать/Вырезать/Переименовать/Удалить»), тап в режиме
  выбора переключает элемент, удержание на пустом месте — меню папки, палец
  прокручивает с инерцией. Скопированное или вырезанное — панель «Вставить сюда?».
  Кнопка «+» — меню «Создать». Выдвижная панель: вкладки и места. Нижний лист
  «Вид и сортировка»: список/сетка, ключ сортировки, по убыванию, папки сверху,
  скрытые файлы. Подменю на телефоне разворачиваются в плоский список.
  «Назад» (жест, Escape) закрывает меню/диалог/лист/панель, отменяет
  переименование, снимает выбор, выходит из поиска, листает историю и лишь
  потом поднимается вверх (не выше домашней папки).
- **Просмотрщик на телефоне**: «назад», имя, сведения и «⋮» (показать в папке,
  копировать, удалить, открыть в программе); стрелок нет — листают смахиванием,
  масштаб — щипком, двойной тап — «вписать ↔ 1:1»; на нижней панели масштаб,
  «вписать» и поворот.

## Настройки (`[files]` в config.toml)

```toml
[files]
view = "details"               # details | list | tiles | icons
icon_size = 64                 # значки в виде icons, px
sort_by = "name"               # name | modified | type | size
sort_descending = false
folders_first = true
show_hidden = false
single_click = false
confirm_trash = false          # спрашивать перед удалением в корзину
preview_pane = false
thumbnails = true
thumbnail_max_mb = 64
pinned = ["~/Projects"]
restore_tabs = true
dir_sizes = false              # размеры папок чипом на значке (считаются в фоне)
sidebar = true                 # боковая панель мест
```

Всё это меняется и в окне: **Настройки** (шестерёнка справа на командной
панели, Ctrl+, или «⋯ → Настройки» на телефоне) — панель выезжает справа:
вид и размер значков, скрытые файлы, боковая панель, размеры папок, папки
сверху, сортировка, миниатюры и их предел, открытие одним щелчком,
подтверждение удаления, восстановление вкладок.

Размеры папок (`dirsize.rs`) считаются в фоне двумя потоками: без перехода по
ссылкам, в пределах одной ФС (как `du -x --apparent-size`), жёсткие ссылки —
один раз; долгий обход показывает промежуточный итог бледным чипом. Обходы
папок, ушедших с экрана, отменяются; посчитанное пересчитывается через минуту
или после операции с файлами внутри. Сортировка «по размеру» тогда сравнивает
объём папок.

Вид, сортировка, скрытые файлы и закреплённые папки сохраняются сами, когда их
меняют в окне. Программа для папок по умолчанию — `[general] file_manager`
(Super+E) и `MimeType=inode/directory` в `synfiles.desktop`.

## Устройство

| Модуль | Что делает |
|---|---|
| `syngui::data::ItemView` | виртуализированная сетка/строки фиксированного размера: выделение, рамка, клавиатура, поиск по буквам, перенос, автопрокрутка, прокрутка пальцем, сенсорный режим (`touch_mode`), сетка на всю ширину (`stretch`) (в syngui — пригодится не только проводнику) |
| `ui/phone.rs` | телефонная раскладка (см. выше) |
| `model.rs` | записи каталога, естественная сортировка, форматы размеров и дат |
| `state.rs` | вкладки и панели на сигналах, загрузка папок в фоне с метками (ответ старой загрузки отбрасывается), inotify, тема, сеанс |
| `actions.rs` | команды, меню, сочетания клавиш |
| `ops.rs` | задания в фоне, конфликты имён, журнал отмены |
| `trash.rs` | корзина freedesktop |
| `thumbs.rs` | пул миниатюр, кэш freedesktop |
| `search.rs` | поиск по имени в ширину |
| `places.rs` | места боковой панели, диски, gvfs |
| `synshell_common::mime` | shared-mime-info (globs2, magic, subclasses), описания, значки, `mimeapps.list` |
| `synshell_common::xdg` | .desktop (с `MimeType=`, подстановкой `%f/%F/%u/%U`), темы значков |

Проверка без экрана — снимок с шагами сценария:

```
synfiles --screenshot out.png --size 1280x800 --view tiles \
    --script 'key:end;key:f2' ~/Документы
```

Шаги: `key:ctrl+a`, `click:x,y`, `rclick:x,y`, `dclick:x,y`, `mclick:x,y`,
`move:x,y`, `drag:x1,y1,x2,y2`, `release:x,y`, `type:текст`, `wait:мс`; палец —
`tap:x,y`, `hold:x,y` (удержание), `swipe:x1,y1,x2,y2`; `back` — «Назад» телефона.
Телефонная раскладка: `--size 400x860 --scale 2`.

## Окно выбора файлов (портал)

Оболочка — бэкенд `org.freedesktop.impl.portal.FileChooser` (OpenFile, SaveFile, SaveFiles;
`synsystem::portal_files`, то же имя шины `org.freedesktop.impl.portal.desktop.synshell`, что и у
бэкенда доступа; `data/synshell.portal`, `FileChooser=synshell;kde;gtk;` в `synshell-portals.conf`).
Программы, которые выбирают файлы через портал (Firefox, Chromium, GTK/Qt/Flatpak, syngui), получают
окно Проводника в режиме выбора:

```
synfiles --choose '{"mode":"open"|"save"|"save_files","title","accept_label","multiple","directory",
                    "filters":[{"name","patterns":[[0,"*.png"],[1,"image/*"]]}],"current_filter",
                    "current_name","current_folder","files":[имена]}'
```

- раскладка телефона или компьютера — по ширине окна; внизу — панель выбора: фильтры типов (чипы),
  имя файла (сохранение), «Отмена» и главная кнопка (`accept_label` портала);
- открыть один файл — касание файла; несколько — касания отмечают, «Открыть»; папку — «Выбрать»
  (текущая или выделенная); сохранить — имя в поле или касание существующего файла, замена — повторное
  нажатие; панель файловых операций в этом режиме скрыта, вкладки прошлого сеанса не открываются;
- ответ — строка JSON в stdout (`{"response":0,"uris":[…],"current_filter":N}`, отмена — `{"response":1}`),
  журнал — в stderr; программа закрыла запрос (`Request.Close`) — окно убивается.
  `SYNSHELL_FILE_CHOOSER` — другая программа окна выбора.
