# Ассистент: план развития

Решения (2026-10-13):

- **Генерация** (картинки, видео, музыка, эмбеддинги) — через службу
  `synaptixd`: она единственный хозяин GPU и уже умеет выгружать модели по
  памяти. Пайплайны из команд `synaptix-cli` выносятся в общий фасад
  `synaptix`, служба получает раннеры, ассистент и любые программы зовут её по
  сокету. Нодовый движок Synthos — позже: безголовое ядро отдельным крейтом,
  служба исполняет граф из JSON.
- **Память** — как в Claude Code: каталог `.md`-файлов (один факт — один файл,
  frontmatter) и индекс `MEMORY.md` в системном промпте; инструменты
  сохранить/прочитать/забыть; каталог задаётся в Параметрах
  (по умолчанию `~/.local/share/synassist/memory`).
- **Базы знаний** — папки с документами: индекс эмбеддингами (bge-m3 в службе),
  инструмент поиска с источниками, переиндексация при изменениях.
- **Инструменты** — в Параметрах: включён ли каждый и режим (сразу /
  спрашивать / запрещён); навыки (skills) — папки с инструкциями, которые
  ассистент подгружает по ситуации.

## Этапы

Каждый этап — законченный результат: собран, установлен, проверен на живой
системе.

1. **Вложения** (готово, pkgrel 53): картинки и видео модели со зрением,
   аудио и звук видео — расшифровкой, PDF — текстом, превью в панели и окне.
2. **Память** (готово, pkgrel 54). `synassist::memory`: каталог, индекс в промпте, инструменты
   `memory_save` / `memory_read` / `memory_forget`; поле каталога в Параметрах
   → «Ассистент»; кнопка «Открыть каталог памяти».
3. **Права инструментов и навыки** (готово, pkgrel 55). Режим на инструмент (allow / ask / deny)
   вместо общего `auto_approve` (со старой настройкой как значением по
   умолчанию); каталог навыков (`SKILL.md` с описанием), список описаний — в
   промпте, инструмент `skill` подгружает тело; страница в Параметрах.
4. **Эмбеддинги и базы знаний** (готово, pkgrel 56). Раннер `embed` в службе (`op: embed`);
   `synassist::kb`: индекс папок (чанки, векторы, mtime), инструмент
   `kb_search`; Параметры: список баз, состояние индексации, переиндексация.
5. **Генерация в службе** (картинки, музыка и видео MiniMax-H3 — готово, pkgrel 58; LTX-2.3 — дальше). Фасады `synaptix::facade::{image, video, music}`
   из команд CLI (flux, flux2, qwen-image, sdxl; ltx, minimax-h3; acestep,
   yue2); раннеры и операции службы с прогрессом и результатом в файле;
   `synaptixctl image|video|music`.
6. **Инструменты генерации у ассистента** (картинки, правка по референсам, музыка, видео с кадрами и референсами — готово, pkgrel 58). `image_generate` / `image_edit` /
   `video_generate` / `music_generate`: модель по умолчанию из службы,
   результат — вложением в чат (превью, ассистент видит картинку).
7. **Нодовый движок.** Безголовое ядро движка Synthos отдельным крейтом;
   служба исполняет граф; ассистент собирает граф под сложные задачи; Synthos
   переходит на ядро.
