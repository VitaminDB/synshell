# syn-video-editor — ИИ-видеоредактор synshell

Монтаж силами ИИ: агент сам строит графы, режет, подбирает переходы, шаблоны и ассеты; человек смотрит
результат и правит. Не клон DaVinci Resolve или After Effects: вход на уровне CapCut, глубина — по требованию.
Задачи — [todo.md](todo.md), выполненное — [done.md](done.md).

## Решения (утверждены 2026-11-24)

- **Где:** крейт `crates/syn-video-editor` в synshell, программа `syn-video-editor`.
- **Агент — главный исполнитель.** Встроен, полный доступ ко всему приложению. Сам делает монтаж, строит
  графы, выбирает переходы и ассеты. Пользователь потом смотрит предпросмотр и правит. Каждый ход агента —
  одна группа отмены, разница таймлайна «до/после», откат одной кнопкой. Подтверждение — только для
  необратимого (удаление файлов, перезапись экспорта).
- **Простота.** Обычный режим: медиатека, просмотр, таймлайн, инспектор (3–6 понятных параметров у блока),
  агент. «Открыть как граф» раскрывает клип, эффект или шаблон в граф — это тот же документ, а не отдельный
  режим. Технические настройки по умолчанию, агент меняет их по просьбе.
- **Интерфейс как в hexspire** (образец — `hexspire/docs/img/reverse-de.png`, код — `hexspire/app/src/ui`,
  `layout.rs`, `layouts.rs`, `commands.rs`):
  - заголовок окна (CSD): знак, меню (Файл, Правка, Монтаж, Шаблоны, ИИ, Вид…), по центру поиск-палитра
    «Команды, файлы, шаблоны…» (Ctrl+Shift+P), кнопки окна;
  - панель инструментов: файл, отмена и повтор, поиск, воспроизведение, кнопка ИИ, разделы и выпадающий
    переключатель вида;
  - док-панели с вкладками на `syngui::widgets::DockState`/`DockSpec`; раскладка сохраняется;
  - виды — сценарии Rhai `library/layouts/<ключ>.rhai` (`//! name`, `fn layout()` → split/tabs), «Сохранить
    шаблоном». Виды: Монтаж, Моушн, Граф, Шаблоны, ИИ, Цвет;
  - строка состояния: проект, позиция, fps и размер, ход рендера и генерации;
  - тёмная тема и плотность hexspire, таблицы и инспектор «ключ — значение».
- **Редактор узлов общий с Synthos:** вынести из `synthos/src/pages/node_editor` в общий крейт, копий нет.
- **Начало — сквозной срез:** импорт → агент режет тишину по транскрипту → титр из шаблона Fusion и LUT →
  RIFE до 60 fps → экспорт mp4.

## Архитектура

### Всё приложение — команды
Одна таблица команд (id, раздел, заголовок, сочетание клавиш, **схема аргументов**, результат). Её вызывают
меню, клавиши, палитра, сценарии Rhai, встроенный агент, CLI (`--cmd`, `--ai`) и внешний сокет (Claude Code
через synlink или MCP). Описания инструментов агента генерируются из таблицы. Действий «только мышью» нет:
перетаскивание на таймлайне в итоге вызывает `clip.move`. Тест проверяет, что у каждой команды есть схема
и она выполняется без окна.

### Два уровня графов, один редактор
- **Граф сценария** — `synaptix-flow`: шаги по секунде и по минуте, исполняет служба synaptixd (LLM,
  генерация, распознавание, ffmpeg, пакетные vfx). На выходе клипы, тексты и **таймлайн**: рецепты
  возвращают редактируемый проект, а не готовый mp4.
- **Граф кадра** — композитинг на GPU в реальном времени: слои, Transform, Merge, маски, текст, ключи,
  переходы, LUT, лёгкие фильтры. Сюда же ложатся шаблоны Fusion.
- **Блок** — подграф с вынесенными параметрами (аналог MacroOperator в Fusion). Импортированный шаблон
  сразу становится блоком.

### Один композитор для просмотра и экспорта
GPU-композитор (wgpu syngui) считает и предпросмотр, и экспорт, поэтому кадры совпадают. ffmpeg только
декодирует (`syngui::video`, hwaccel) и кодирует (`syn-media` venc). Фильтрграф ffmpeg для эффектов не
используется.

### Моушн-графика
Ключ у любого параметра, редактор кривых (bezier, ease, back, elastic), путь движения на просмотре. Слои:
текст, фигуры, медиа, группы; родитель и потомок, маски, режимы наложения. Анимация текста посимвольно,
по словам и строкам (аналог StyledTextFollower). Пресеты движения — блоки. Позже: трекинг, маски по
сегментации, частицы, 2.5D.

### Фильтры
- **Лёгкие** — шейдеры графа кадра: цвет, LUT `.cube`, резкость, размытие, свечение, шум, виньетка.
- **Нейросетевые** — `synaptix-vfx` (PLKSR, SPAN, Compact, NanoVSR — увеличение; RIFE — интерполяция) через
  тот же `FrameFilter`, что у плеера:
  - увеличение — способ привести клип к разрешению проекта («Улучшить: ×2 нейро»);
  - RIFE — способ пересчитать частоту кадров (клип 24/30 → проект 60) и плавное замедление;
  - пресет экспорта «4K 60 fps (нейро)»;
  - ноды `vfx_upscale` и `vfx_interpolate` в графе кадра и в `synaptix-flow` (пакетная обработка);
  - кэш результата по клипу; без CUDA фильтр помечается недоступным, проект не ломается.

### Шаблоны
- **Fusion `.setting`.** Библиотека `~/Storage/Видеомонтаж/DaVinci Resolve`: 1662 шаблона, 110 видов
  инструментов. Ядро: Transform, Merge, Background, Rectangle/Ellipse/Polyline-маски, TextPlus/StyledText,
  BezierSpline, Dissolve, Gradient, KeyStretcher, ColorCurves, BrightnessContrast. Хвост: Blur,
  DirectionalBlur, Glow, Displace, `Fuse.Duplicate` (60 файлов, Lua — повторить своим кодом), частицы и 3D
  — позже. Инструмент-отчёт покрытия решает, что делать следующим.
- **LUT `.cube`** — 3820 файлов, 3D-текстура.
- **After Effects — через Lottie** (`syngui::lottie`), не `.aep`.
- **Галерея как в CapCut:** композитор без окна заранее готовит короткие циклы, при наведении шаблон
  проигрывается вживую с вашим текстом и клипом.

### ИИ
- **Ядро агента** — `syn-assist` (цикл, навыки, память, база знаний, сжатие контекста), модели — synaptixd.
- **Что видит агент:**
  - документ — таймлайн компактным текстом;
  - контекст — выделение, позиция воспроизведения, вид, ошибки, ход рендера и генерации;
  - медиатеку — индекс (транскрипт, дикторы, сцены, описания кадров, бит, эмбеддинги);
  - глаза — кадр просмотра и миниатюры через модель зрения.
- **Массовые правки — сценарием Rhai** за один вызов. Долгая генерация идёт в фоне, агент получает события.
- **Самопроверка:** контрольные кадры после монтажа смотрит модель зрения.
- **Навыки:** Reels из длинного видео, подкаст, клип под музыку, говорящая голова.
- **Bash не даём:** доступ к файлам — каталоги проекта и медиатеки.

### Формат проекта
`.syn` (`synaptix-bundle`) с видом `video-project` в `BundleMeta`. Внутри манифест таймлайна текстом (JSON,
чтобы удобно сравнивать и чтобы правил агент), прокси, миниатюры, кэш индексации. Медиа по умолчанию
хранятся ссылками, «Упаковать проект» встраивает их. Доработки bundle: не-тензорные чанки, новые `FileTag`.

## Этапы
| Этап | Содержание |
|---|---|
| 0. Каркас | Крейт, окно с CSD, таблица команд со схемами, сокет, агент на syn-assist, формат v0, вынос редактора узлов |
| 1. Движок | Документ (дорожки, слои, ключи), GPU-композитор, декод и прокси, экспорт, отмена и повтор |
| 2. Простой монтаж | Медиатека, таймлайн, просмотр, инспектор; каждое действие — команда, проверка агентом |
| 3. Моушн и фильтры | Слои, ключи, кривые, анимация текста, пресеты; лёгкие фильтры и LUT; увеличение, RIFE, 60 fps |
| 4. Шаблоны | Fusion и Lottie, галерея с живым предпросмотром, отчёт покрытия |
| 5. Графы и блоки | Ноды таймлайна и vfx в synaptix-flow, блоки, рецепты возвращают проект |
| 6. ИИ-монтаж | Индексация медиатеки, навыки, самопроверка по кадрам |

Критерий готовности любой функции: работает в интерфейсе, работает у агента, и агент сам находит её по
словам пользователя (живой прогон).
