# Задачи syn-video-editor

План и решения — [plan.md](plan.md). Выполненное переносить одной строкой в [done.md](done.md).

## Этап 0. Каркас (остаток)
- [ ] Виды-раскладки Rhai `library/layouts/*.rhai` (Монтаж, Моушн, Граф, Шаблоны, ИИ, Цвет), «Сохранить шаблоном»
- [ ] Панель ИИ: Markdown в ответах, разница «до/после» хода, кнопка «Стоп»
- [ ] Сокет команд (`$XDG_RUNTIME_DIR/syn-video-editor.sock`): те же команды снаружи (Claude Code, synlink)

## Этап 1–2. Движок и ручной монтаж
- [ ] Звук при воспроизведении в окне (сейчас — только при экспорте)
- [ ] Перетаскивание: медиа → таймлайн, клипы по дорожкам, края клипов (trim) мышью, привязки
- [ ] Инспектор с правкой полей (скорость, громкость, параметры эффектов, текст титра)
- [ ] Ускорить экспорт (сейчас 1080×1920 30 fps ≈ 1,5× реального времени; RIFE 1080p ≈ 0,4 с/кадр)
- [ ] Шрифты титров: подключить папку `Шрифты` библиотеки (сейчас нет — подставляется запасной)

## Этап 3. Моушн и фильтры
- [ ] Ключи у любого параметра, редактор кривых, путь движения на просмотре
- [ ] Анимация текста по символам/словам, пресеты движения
- [ ] Резкость, переходы между клипами (Dissolve, слайды, зум), LUT на GPU

## Этап 4. Шаблоны
- [ ] Исполнитель графа Fusion: Transform, Merge, Background, маски, BezierSpline, Dissolve, Glow/Blur
- [ ] Отчёт покрытия библиотеки (сколько из 1662 шаблонов исполняются полностью)
- [ ] Галерея шаблонов с живым предпросмотром (наведение — проигрывание), Lottie

## Этап 5. Графы и блоки
- [ ] Граф кадра клипа на общем `syn-node-editor`: список эффектов = линейный граф; ноды Transform, LUT, Цвет, Увеличение, RIFE, Merge
- [ ] Ноды таймлайна и vfx в synaptix-flow (пакетная обработка), рецепты возвращают проект
- [ ] Блоки: подграф с вынесенными параметрами

## Этап 6. ИИ-монтаж
- [ ] Индексация медиатеки: описания кадров (модель зрения), сцены, бит музыки, поиск по смыслу
- [ ] Самопроверка агента по кадрам (frame.export → модель зрения)
- [ ] Навыки: Reels из длинного видео, подкаст, клип под музыку, говорящая голова
