# Задачи syn-video-editor

План и решения — [plan.md](plan.md). Выполненное переносить одной строкой в [done.md](done.md).

## Этап 0. Каркас
- [ ] Окно с CSD как в hexspire: заголовок с меню и палитрой, панель инструментов с переключателем видов, док-панели (DockState), строка состояния, F11/Esc
- [ ] Палитра команд (Ctrl+Shift+P) и меню из таблицы команд; горячие клавиши из `Command::shortcut`
- [ ] Виды-раскладки Rhai `library/layouts/*.rhai` (Монтаж, Моушн, Граф, Шаблоны, ИИ, Цвет)
- [ ] Панель ИИ в окне: чат, ход инструментов, разница «до/после», откат хода
- [ ] CLI `--screenshot` (снимок окна без экрана)
- [ ] Сокет команд (`$XDG_RUNTIME_DIR/syn-video-editor.sock`): те же команды снаружи
- [ ] Вынос редактора узлов из Synthos в общий крейт `syn-node-editor` (идёт отдельной задачей)

## Сквозной срез
- [ ] Прокси и миниатюры медиатеки
- [ ] Транскрипт (whisper в службе) → команда «вырезать тишину» → агент делает её по просьбе словами
- [ ] Титр из простого шаблона Fusion (TextPlus + Transform + Merge, BezierSpline) поверх видео
- [ ] Композитор GPU: просмотр кадра таймлайна (клипы, титры, LUT, затухания)
- [ ] Экспорт mp4 с RIFE до 60 fps (synaptix-vfx)
