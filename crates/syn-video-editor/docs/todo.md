# Задачи syn-video-editor

План и решения — [plan.md](plan.md). Выполненное переносить одной строкой в [done.md](done.md).
Порядок: этапы и пункты по порядку; после каждого пункта — установка и проверка пользователем.
Замечание о том, что запланировано позже, — «по плану» (этап, пункт); нового в плане нет — вносить сюда или делать сразу.

## Этап A. Ручной монтаж без шероховатостей
- [x] A1. Звук при воспроизведении (сведение тем же построителем, что экспорт; часы по звуку) — на проверке
- [x] A1a. Панель управления под просмотром (в начало, кадр назад, пуск/пауза, стоп, кадр вперёд, в конец, время); перетаскивание курсора позиции и протяжка по линейке — на проверке
- [x] A1b. Вид клипов (на проверке): миниатюра в начале клипа (по высоте блока), раскадровка по длине, волна звука на аудиоклипах и клипах со звуком
- [x] A2. Инспектор с правкой (на проверке): скорость, громкость, имя, параметры эффектов (ползунки, цвет, файл LUT), текст и стиль титра, длительность перехода — каждое поле командой с отменой
- [ ] A3. Клавиши и мышь: S — разрез, Delete / Shift+Delete, Ctrl+C/V, стрелки; выделение рамкой и с Ctrl, перенос нескольких клипов; привязки к краям, позиции, началу; масштаб Ctrl+колесо и щипок, ползунок масштаба в шапке таймлайна
- [ ] A4. Контекстное меню клипа: разрезать, удалить, переход, эффект, отделить звук, инспектор
- [ ] A5. Дорожки: звук и видимость кнопками в заголовке, переименование, удаление пустой, порядок перетаскиванием
- [ ] A6. Шрифты титров из папки `Шрифты` библиотеки
- [ ] A7. Ускорение экспорта: конвейер (чтение, композитор, кодер параллельно), NVENC/VAAPI, RIFE пакетами

## Этап B. Моушн-графика
- [ ] B1. Ключи у параметров (положение, масштаб, поворот, прозрачность, цвет, размытие, титр); ромбики на клипе и в инспекторе
- [ ] B2. Редактор кривых (ease, back, elastic, bezier), панель «Кривые»
- [ ] B3. Путь движения и рамка масштаба/поворота прямо на просмотре
- [ ] B4. Анимация текста по символам, словам, строкам (появление, сдвиг, разброс, печать)
- [ ] B5. Пресеты движения плитками с превью
- [ ] B6. Слои: фигуры, маски, режимы наложения, родитель и потомок
- [ ] B7. Вид «Моушн»

## Этап C. Шаблоны Fusion и галерея
- [ ] C1. Исполнитель графа Fusion: Transform, Merge, Background, маски, TextPlus, BezierSpline, Dissolve, Gradient, KeyStretcher; затем Blur, Glow, Displace, Fuse.Duplicate
- [ ] C2. Отчёт покрытия библиотеки (1662 шаблона)
- [ ] C3. Параметры шаблона в инспекторе (входы MacroOperator)
- [ ] C4. Галерея шаблонов с живым превью при наведении, поиск, перенос на таймлайн
- [ ] C5. Переходы Fusion из библиотеки
- [ ] C6. Lottie
- [ ] C7. LUT плитками с превью на кадре клипа

## Этап D. Графы и блоки
- [ ] D1. Граф кадра клипа: «Открыть как граф», эффекты и нейрофильтры — ноды, ветвления, Merge
- [ ] D2. Блоки: подграф с вынесенными параметрами, плитка в «Эффектах»
- [ ] D3. Ноды сценария synaptix-flow: медиатека, таймлайн, паузы, субтитры, vfx_upscale/vfx_interpolate
- [ ] D4. Рецепты возвращают редактируемый проект
- [ ] D5. Шаблоны графов в галерее

## Этап E. ИИ-монтаж
- [ ] E1. Индексация медиатеки: расшифровка, дикторы, сцены, описания кадров, бит, поиск по смыслу
