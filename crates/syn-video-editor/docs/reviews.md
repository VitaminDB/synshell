# Разборы готовых фильмов агента

Наблюдения по итогам живых прогонов. Сюда — история и примеры, в навыки — только
общие правила, которые из них выведены.

## 2026-11-28 — мультфильм «Суп для короля» (1:45, 7 сцен), оценка пользователя 2/10

| Беда | Что было | Правило / код |
|---|---|---|
| Короткая история | 7 сцен по 12–21 с, нет ставок, соперника, причины победы; поворот ничего не меняет | `screenplay`: длина от истории (по умолчанию ≥ 5 мин), три акта, чек-лист до съёмки |
| Скучная камера | 2 композиции на весь фильм (кухня 33 с, площадь 60 с), всё — продолжение по хвосту | `screenplay` «Раскадровка по кадрам», `minimax-h3` «Несколько планов в ролике»; каркас `scene.plan` — `[Shot 2] At …`, `[CUT]` для нового плана |
| Событий нет в кадре | нет моста и падения в воду, суп не на короле, лицо закрыто паром | `frame.check` с `file` (кадр ролика до таймлайна); ответ `ref-scenes` требует проверить события |
| Речь в немых сценах, повторы | «…не опоздай», «…Борщ Третий», «Суп побеждает» ×2 | `ref-scenes` распознаёт речь каждого ролика (`speech_problem`); каркас немого ролика — явный запрет речи |
| Дубль 10,7 с на 2 слова | Drama 3 повторила фразу | `voice.say`: `take_problem` — длина против слогов, лишние слова |
| Реквизит перепутан | котёл героев и котёл-приз — одно и то же | `screenplay` «Реквизит — как герои»: свой эталон предмета |
| Нет музыки | только звук H3 | команда `music.make` (MiniMax Music 3), тема в `video-story` |
| Тёмная сцена, плашка титров | ночь не читается, финальная карточка в центре кадра | правила света; `cinematic_montage` — карточка внизу, музыка тише |
| «Год 2025» в титрах | модель взяла год из обучения | `skill.run`: год выпуска в надписях — текущий (`current_year_in`) |

Проверка речи на роликах этого фильма нашла ровно те три места, что и ручной разбор (сцены 2, 5 и повтор в сцене 7).
