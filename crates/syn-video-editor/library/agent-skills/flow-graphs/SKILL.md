# Графы сценариев

- `nodes_tabs` — открытые графы; `activate` — переключиться.
- `nodes_show` — ноды с #id, подграфы, провода и поля текущего графа.
- `nodes_group {nodes: [#id…], title}` — объединить любые ноды (и подграфы) в подграф; `nodes_ungroup {node}` — развернуть.
- Прогон графа запускает пользователь кнопкой ▶ панели; готовые графы — «Шаблоны → Графы».
- Ноды служб (LLM, картинка, видео, музыка, речь, распознавание, нейроувеличение) с пустым полем «Модель» берут модель из настроек «Модели»; явное поле важнее.
