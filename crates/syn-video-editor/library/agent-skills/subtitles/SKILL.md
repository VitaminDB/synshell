# Субтитры

1. Найди клипы с речью: `project_dump` (видео со звуком или звуковые клипы).
2. Расшифровка: `media_transcribe id` (язык — `language`, по умолчанию определится сам; модель распознавания — из настроек). Уже есть — `media_transcript id` покажет фразы.
3. Титры: `subtitles_add {ids, max_chars, size, style}` — ставит фразы на дорожку «Субтитры» по таймкодам клипов.
   - `style: "reels"` — крупно по словам для вертикальных роликов;
   - `max_chars` 30–42 для горизонтального кадра, 16–24 для 9:16.
4. Оформление всех титров разом — `script_run` (обход дорожки «Субтитры» и `clip_set style`).
5. Проверка: `frame_check` на 2–3 фразах — читаются ли, не перекрывают ли лицо и важное, не обрезаны ли краем кадра.

Опечатки распознавания исправляй `clip_set text` по смыслу, не выдумывая слов.
