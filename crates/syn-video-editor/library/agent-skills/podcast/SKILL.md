# Подкаст и интервью

1. `media_index {speakers: true}` — расшифровка и дикторы.
2. Быстрый путь: `skill_run name=podcast` (паузы, подписи дикторов). Одна камера с говорящим — `skill_run name=talking_head` (паузы, наезды на чередующихся кусках, субтитры).
3. Доработка: оговорки и повторы — `clip_cut_ranges` по таймкодам `media_transcript words:true`; нижние трети с именами — навык motion-graphics или fusion-templates.
4. Проверка `frame_check` на подписи каждого диктора.
