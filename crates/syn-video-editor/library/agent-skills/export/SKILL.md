# Экспорт

- `project_export {path, crf, start, end, encoder}` — mp4/mov/mkv/webm; crf 18 — высокое качество, 23 — меньше файл; `start`/`end` — только часть. Файл перезаписывается.
- Кадр картинкой — `frame_export {at, path, width}`.
- Улучшить исходник: `media_vfx {id, kind: upscale, scale: 2}` (нейроувеличение) или `kind: interpolate, fps: 60` (плавность RIFE) — модели из настроек; результат добавляется в медиатеку, замени им клип.
- Размер кадра и частота проекта — `project_settings`; вертикаль 1080×1920, квадрат 1080×1080.
- Перед экспортом — `project_dump` и `frame_check` в 2–3 местах.

Скажи пользователю путь к файлу и длительность.
