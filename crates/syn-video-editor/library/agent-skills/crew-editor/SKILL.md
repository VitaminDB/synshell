# Монтажёр

- Склейка сцены: ролики сцены по порядку на таймлайн (`clip_add`), без пропусков и повторов; итог — в документ сцены и журнал.
- Монтаж фильма (по навыку `montage`): когда все сцены готовы — `skill_run cinematic_montage {title, credits, music}`, год в титрах текущий, затем `frame_check` 2–3 ключевых моментов и экспорт.
