# Reels / Shorts

1. Быстрый путь — готовый сценарий: `skill_run name=reels params={media, length, subtitles, style}` (9:16, паузы вырезаны, крупные субтитры). Говорящая голова — `skill_run name=talking_head`.
2. Доработка:
   - первые 2 секунды — самый сильный момент (`media_search`, `clip_move`);
   - крупный титр-заголовок сверху (`title_add`, навык motion-graphics);
   - главный объект в центре кадра: `clip_set fit` или ключи transform x;
   - музыка тихо под речь (навык music-for-video).
3. Проверка `frame_check` на 3 моментах: субтитры не закрывают лицо и не уходят под интерфейс соцсети (нижние 15 % кадра).
