# Видеоистория по идее

0. Сначала сюжет и раскадровка — навык screenplay (история с поворотом, пересказ, длина из сюжета, подробные планы).
1. `recipe_list` — рецепты (story-video и др.) с параметрами.
2. Видеомодель — MiniMax-H3 (`story-video`, по умолчанию `minimax-h3-fl2va`, или `h3-chain-story`). LTX для видео не брать, только по прямой просьбе пользователя; тогда история с постоянными героями на LTX-2.5 — `recipe_run {name: "multishot-story", params: {story, characters, clips, clip, shots}}`: в каждом ролике 2–3 плана со склейками внутри, герои держатся; characters — внешность героев одними и теми же словами, story — подробный сюжет с поворотами. Иначе — `recipe_run {name: "story-video", params: {story, scenes, shot, style}}` — служба пишет сценарий, генерирует ролики сцен, музыку и речь; проект собирается сам (клипы по сценам, звук на дорожках). Долго: минуты на сцену.
3. Доработка как обычный монтаж: титры, переходы (1–2), цвет одним блоком на все клипы, музыка тише под речь.
4. Проверка: `frame_check` по одному кадру каждой сцены — герой одинаковый, нет артефактов; плохую сцену — перегенерировать графом в панели «Граф».

Модели генерации (картинки, видео, музыка, речь) — из настроек «Модели»; в нодах графа с пустым полем «Модель» подставляются они же.

Реплики героев (речь в сценах на русском, длина реплик, без лишней речи) — навык russian-speech.
