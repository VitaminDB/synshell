# Видеоистория и мультфильм по идее

0. **Сценарий, кастинг и раскадровка:** обязательно загрузи навык `screenplay` (драматургия с поворотом, пересказ, длина из сюжета, отдельные описания всех нужных героев и локаций, профессиональная работа камерой, `[CUT]` на сменах локаций). Реплики на русском — по навыку `russian-speech`.
1. **Видеомодель — MiniMax-H3 Ref2VA** (`minimax-h3-ref2va`). LTX (2.3, 2.5) не брать, только по прямой просьбе пользователя (тогда `multishot-story`).
2. **Генерация:**
   - **Целиком одной командой:** `recipe_run {name: "story-video", params: {story, characters, locations, scenes, shot, style, lang, chain, image_model, lora}}` — рисует отдельные референсы всех героев и локаций (моделью картинок из настроек, например Qwen-Image 2.1, или `image_model`), снимает сцены с по-сценным отбором `<Picture k>` и автосбросом хвоста на `[CUT]`, собирает редактируемый проект на таймлайне и возвращает пути всех референсов.
   - **Поэтапно / подмена героя или локации по пути / пересъёмка сцены:**
     - `recipe_run {name: "ref-image", open: false, params: {prompt, style, base, image_model}}` — создать нового героя/локацию или переодеть/изменить существующий референс (передав его в `base` для Qwen-Image 2.1 / FLUX.2);
     - `recipe_run {name: "ref-scenes", open: false, params: {refs, storyboard, style, shot, chain, lora}}` — снять акт или переснять 1–N сцен с обновлённым списком `refs` и тегами `<Picture k>` / `[CUT]`, затем поставить на таймлайн (`media_import` + `clip_add`).
   - Для максимального киношного качества («как полнометражный 3D-мультфильм») можно передать `lora: "off"` (20 шагов вместо Turbo 8 — дольше, но богаче фактура и мимика).
3. **Контроль качества:** проверь ключевые кадры сцен через `frame_check` — герои и локации держатся, нет артефактов. Если сцена вышла слабой или герой «поплыл» — пересними именно её через `ref-scenes` с теми же (или подправленными через `ref-image`) референсами и замени клип на таймлайне.
4. **Финальный монтаж:** оформи `skill_run cinematic_montage` (название, титры, единый цвет, звук).

Модели генерации (картинки, видео, музыка, речь) при пустом поле `model` / `image_model` берутся из настроек «Модели».
