# Фильм / мультфильм: порядок работы

Загрузи навыки: `screenplay` (режиссура: история, кадры, проверки), `minimax-h3` (промпт видео), `drama3` (озвучка), `qwen-image` (эталоны). Видео — только MiniMax-H3 Ref2VA; LTX — только по прямой просьбе (навык `ltx`).

## Главный способ: пакет документов и сцена за сценой
Фильм не пишется целиком заранее: в работе всегда только общие документы и текущая сцена. Так длинный фильм не захлёстывает контекст, а каждая сцена проверяется до съёмки.

### Документы проекта (`doc.write`, в папке проекта; ответ записи содержит замечания проверок — устраняй их до следующего шага)
- **`00_оригинал`** (по готовому сценарию) — дословный перевод источника, пополняется по одной сцене: раздел `## Сцена N (стр. <страница PDF>)` — перевод 1:1 всего текста сцены из `source.scene`, без сокращений и склеек (`doc.write` с `append: true`). Проверка: раздел есть и по объёму сопоставим с источником; без него `scene_NN` не запишется.
- **`01_библия`** — коротко на весь фильм: словарь имён (написание и произношение; для готового сценария — транскрипция по оригиналу), герои (внешность, возраст, голос — из источника или истории), локации (чьё место, что в нём есть), реквизит (что, где лежит, у кого), стиль, правила брани и мата (по указанию пользователя). Проверка: имена против источника.
- **`02_сверка`** (по готовому сценарию) — таблица фактов по сценам: `| N | место (чьё) | кто в кадре | что делают (ключевые события) | реквизит (где, у кого) | кто притворяется или скрывается | ✓/✗ |`; ✓ или ✗ — по каждому факту сцены против источника. Строку сцены N заполняешь после `scene_NN`. Пока строки нет или в ней ✗, код не начнёт озвучку, план и съёмку сцены N; ✗ — исправь `scene_NN` и строку.
- **`03_структура`** — акты и список всех сцен: номер, место, время, кратко событие, длительность `~N с`. Для готового сценария — сцены источника 1:1 в его порядке; длина фильма — не меньше ~80 % от «страница ≈ минута», если пользователь не просил короче. Проверка: число сцен и длина.
- **`04_ассеты`** — каталог ассетов фильма, растёт по сценам: `| id | тип | вариант | base | файл | сцены |`. Тип — герой, локация, реквизит. Вариант — ракурс (анфас, 3/4, профиль, спина), состояние (одежда, раны, связан, мокрый), для локации — точка съёмки (общий, обратная точка, угол, вход, окно) и время суток; у базового эталона — «базовый». base — id базового эталона, от которого вариант сделан правкой. Файл — полный путь из ответа `ref-image`. Сцены — где используется. Проверка: файлы на месте, каждый вариант — от базового эталона того же героя или локации.
- **`scene_NN`** (`scene_01`, `scene_02`, …) — документ текущей сцены (раздел «Документ сцены» ниже). Документ сцены N+1 код не даст записать, пока сцена N не снята.
- **`журнал`** — что ты менял и почему (пересъёмки, правки по замечаниям, решения).
- **`монтаж`** — в конце: порядок, склейки, титры, музыка.
- Итоговый **`сценарий`** не пишется заранее: в конце `script.assemble` собирает его из `scene_NN`.

### Порядок
1. **Подготовка:**
   - готовый сценарий пользователя (вложение) — `source.scene` без номера даёт список его сцен; идея пользователя — сначала история по навыку `screenplay` (три акта, чек-лист);
   - `01_библия` и `03_структура`; перескажи пользователю сюжет в 3–5 предложениях.
2. **Базовые эталоны** (навык `qwen-image`): **один** базовый эталон на героя (во весь рост), на локацию (пустая, общий план) и на важный реквизит — `recipe_run {name: "ref-image", open: false, label: "Эталон: <имя>", asset: "<имя>", params: {prompt, style, width, height, negative}}`; сразу в `04_ассеты` строкой «базовый». **Все варианты** (другой ракурс героя, другая точка локации, другое состояние) — только правкой базового в Qwen-Image edit: `ref-image` с `base: [<файл базового>]` и описанием только изменения, а не новой генерацией — так лицо, одежда, архитектура и свет не «текут». Вариант делается, когда он впервые нужен сцене, и дальше переиспользуется. Остальные базовые — когда герой или локация впервые появятся.
3. **Голоса героев** (навык `drama3`): `voice.cast {name, text}` — по мере появления героев.
4. **Музыкальная тема**: `music.make {prompt: <жанр, настроение, инструменты, темп по-английски>, seconds: <длина фильма>, name: "тема"}`.
5. **Каждая сцена N по порядку** (порядок проверяет код):
   1. перечитай `01_библия`, `03_структура` и документ прошлой сцены (`doc.read`);
   2. **дословный перевод сцены** (для готового сценария): `source.scene {scene: N}` — текст только этой сцены источника; допиши его перевод 1:1 разделом `## Сцена N (стр. …)` в `00_оригинал` (`append: true`);
   3. **`scene_NN`** — проверенная версия сцены по навыку `screenplay` («Адаптация», правила перевода реплик), со ссылками на свой раздел `00_оригинал` и строку `02_сверка`: перевод (действие и реплики `ИМЯ [подача]: «реплика»`), кадры (крупность, камера, длительность), эталоны (какие нужны, пути), свет, время, погода, пейзаж, звук по кадрам (фон — постоянный звук места; события — точные звуки к действиям: дверь, шаги, свист чайника, выстрел, вода; без речи; музыка — в монтаже, не здесь), преемственность с прошлой сценой (одежда, раны, реквизит, где кто стоит), ключевые события для проверки. Ответ записи вернёт текст сцены источника — сверь с ним факты (место, кто, что делает, реквизит, кто притворяется, порядок событий) и перезапиши при расхождении;
   3½. **сверка**: строка сцены N в `02_сверка` (`doc.write` с `append: true` или перезапись таблицы) — факты `scene_NN` против источника, ✓/✗ по каждому; ✗ — исправь `scene_NN`, пока строка не станет вся ✓;
   4. **ассеты сцены**: у каждого кадра в `scene_NN` — точные `@<id>` из `04_ассеты` (ракурс героя и точка локации под крупность и направление камеры, состояние по преемственности); чего нет — сделай (базовый или вариант правкой базового) и внеси в каталог. Съёмку сцены код не начнёт, пока все её `@<id>` не готовы;
   5. **реплики**: `voice.say {text, voice: "<герой>", scene: "<N>", name: "сцена-<N>-<герой>-<k>"}` — один дубль; переозвучивай только при «переозвучь»;
   6. **план**: `scene.plan {scene: N, title, action_seconds, lines: [{file, speaker, action_before}, …]}`;
   7. **съёмка**: один `recipe_run {name: "ref-scenes", label: "Сцена <N> из <M>: <название>", asset: "Сцена <N>", params: {refs: [файлы ассетов кадров сцены из каталога…, дорожки роликов из плана…], storyboard: <по строке на ролик плана>, shot: <длина роликов без речи>, style: "", chain: true, lang: <язык реплик>, width: 960, height: 544}}` — кадры по раскадровке (`[Shot 2] At …`, новый план — `[CUT]`), биты действия с таймкодами, свои `<Audio k>`;
   8. **проверка**: «ПРОВЕРКА РЕЧИ» в ответе (речь в немом ролике, чужие слова сверх реплик, пропавшие звуки окружения, пропавший звук) — пересними названные ролики или положи недостающий звук отдельной дорожкой; ключевые события — `frame_check {file, at, question}`; не прошло — пересними;
   9. **склейка сцены**: ролики на таймлайн по порядку (`clip_add`); допиши в `scene_NN` статус, промпты роликов, файлы озвучки и результаты проверки; строку — в `журнал`.
6. **Повтор ролика**: `ref-scenes` с одной строкой и `open: false`, затем заменить клип.
7. **В конце**: `script.assemble` (итоговый сценарий из сцен), `монтаж`, `skill_run cinematic_montage {title, credits, music: <путь темы>}` — год в титрах текущий; `frame_check` 2–3 ключевых моментов и экспорт.

Строку ролика начинай с каркаса из ответа `scene.plan` (поля по порядку, `<Audio k>`, метки говорящих, правило речи) и заполни места <…> по сценарию: герои, локация и реквизит (`<Picture k>`), кадры и камера, где кто стоит и куда смотрит, действие по битам с таймкодами (навык `minimax-h3`).

## Быстрый способ без озвучки заранее
`recipe_run story-video` — всё одной командой, но речь H3 придумывает сам: возможны акцент и чужие слова. Брать для роликов без важных реплик.

Модели при пустом `model` / `image_model` — из настроек «Модели». Drama 3 и H3 вместе в видеокарту не помещаются — озвучка сцены идёт до её съёмки, служба выгружает модели сама.
