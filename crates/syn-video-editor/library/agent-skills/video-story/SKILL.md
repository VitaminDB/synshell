# Фильм / мультфильм: порядок работы

Загрузи навыки: `screenplay` (режиссура: история, кадры, проверки), `minimax-h3` (промпт видео), `drama3` (озвучка), `qwen-image` (эталоны). Видео — только MiniMax-H3 Ref2VA; LTX — только по прямой просьбе (навык `ltx`).

## Главный способ: речь заранее, H3 — губы, шумы и действие
1. **Сценарий и диалоги — первым делом, до любой генерации.**
   - Идея пользователя — напиши историю по навыку `screenplay` (три акта, длина от истории, чек-лист) и `doc.write {name: "сценарий", text}` по его шаблону: логлайн, чек-лист, герои, локации, **реквизит**, акты и **каждая сцена отдельным разделом** с ключевыми событиями, кадрами, действием по битам, звуком и репликами.
   - Готовый сценарий пользователя (вложение, документ) — по навыку `screenplay`, «Адаптация готового сценария»: перенеси его **целиком** (все сцены, порядок, говорящие, флешбэки), имена — транскрипцией по произношению оригинала, название и говорящие слова — переводом по смыслу (игру слов передать или пояснить), без смеси алфавитов, внешность и быт — из источника, длина — честная по объёму сцен; добавь к каждой сцене кадры, ключевые события и действие по битам. Язык реплик — как в оригинале, если пользователь не попросил перевод (тогда — адаптивный перевод).
   - `doc.write {name: "диалоги", text}` — все реплики по сценам: сцена, говорящий, реплика (по-русски — с буквой ё), указания игры в [скобках] для Drama 3.
   - Пройди чек-лист `screenplay` и перескажи пользователю сюжет в 3–5 предложениях. **Перед каждой сценой перечитывай** `doc.read` «сценарий» и «диалоги» — пользователь мог их править.
2. **Эталоны** (навык `qwen-image`): каждый герой во весь рост, каждая локация пустая (со всем, что понадобится в её сценах), **каждый важный предмет** — `recipe_run {name: "ref-image", open: false, label: "Эталон: <имя>", asset: "<имя>", params: {prompt, style, width, height, negative}}` по одному; **`asset` обязателен**; путь из ответа — это `<Picture k>`.
3. **Голоса героев** (навык `drama3`): `voice.cast {name, text}`; голос подходит герою. Сообщи пользователю, какие голоса получились.
4. **Музыкальная тема**: `music.make {prompt: <жанр, настроение, инструменты, темп по-английски>, seconds: <длина фильма>, name: "тема"}` — для монтажа (шаг 7).
5. **Сцена за сценой — обязательный порядок (его проверяет код).** Озвучка, план и съёмка сцены N+1 отказывают, пока сцена N не снята. Все сцены разом — только по прямой просьбе: `story.mode {all_at_once: true}`. Где ты — `story.status`. Для каждой сцены:
   1. перечитай «сценарий» и «диалоги» (`doc.read`);
   2. **реплики**: `voice.say {text, voice: "<герой>", scene: "<N>", name: "сцена-<N>-<герой>-<k>"}` — один дубль на реплику. Переозвучивай (другой `seed`, тот же `name`) только когда ответ говорит «переозвучь»: не те слова, аномально длинный дубль, лишние слова или повторы;
   3. **план**: `scene.plan {scene: N, title, action_seconds, lines: [{file, speaker, action_before}, …]}`. Сцена длиннее 18 с делится на ролики в тишине; ответ — ролики с временем реплик, окнами без речи и дорожками, план — в документе «раскадровка»;
   4. **съёмка**: один `recipe_run {name: "ref-scenes", label: "Сцена <N> из <M>: <название>", asset: "Сцена <N>", params: {refs: [эталоны героев, локации и реквизита сцены…, дорожки роликов из плана…], storyboard: <по строке на ролик плана>, shot: <длина роликов без речи>, style: "", chain: true, lang: <язык реплик>, width: 960, height: 544}}`. Длину ролика с речью служба берёт по его дорожке. В строке — **кадры по раскадровке** (`[Shot 2] At …` внутри ролика; новый план той же сцены — строка с `[CUT]`), биты действия с таймкодами, свои `<Audio k>`. Продолжение по хвосту (`continues seamlessly…`) — для непрерывного действия; первый ролик сцены той же локации без `[CUT]` начинается с хвоста прошлой сцены (подставляется сам) — его начало как конец того ролика;
   5. **звук** — это звук роликов H3 (речь из дорожек, шумы); отдельную дорожку речи поверх не клади;
   6. **проверка — обязательно, до следующей сцены**:
      - речь: ответ `ref-scenes` распознаёт её сам; «ПРОВЕРКА РЕЧИ» — пересними названные ролики (`ref-scenes` с одной строкой);
      - события: каждое ключевое событие сцены — `frame_check {file: <ролик>, at: <секунда>, question: "<произошло ли событие? видно ли лицо <героя>? тот ли <предмет>? освещено ли?>"}`; нет — уточни строку (событие отдельным битом или планом) и пересними;
      - ролики на таймлайн по порядку (`clip_add`).
6. **Повтор ролика**: `ref-scenes` с одной строкой и `open: false`, затем заменить клип.
7. **Монтаж**: `skill_run cinematic_montage {title, credits, music: <путь темы>}` — год в титрах текущий; затем `frame_check` 2–3 ключевых моментов и экспорт.

Строку ролика начинай с каркаса из ответа `scene.plan` (поля по порядку, `<Audio k>`, метки говорящих, правило речи) и заполни места <…> по сценарию: герои, локация и реквизит (`<Picture k>`), кадры и камера, где кто стоит и куда смотрит, действие по битам с таймкодами (навык `minimax-h3`).

## Быстрый способ без озвучки заранее
`recipe_run story-video` — всё одной командой, но речь H3 придумывает сам: возможны акцент и чужие слова. Брать для роликов без важных реплик.

Модели при пустом `model` / `image_model` — из настроек «Модели». Drama 3 и H3 вместе в видеокарту не помещаются — озвучка сцены идёт до её съёмки, служба выгружает модели сама.
