# Видеоистория по идее

1. `recipe_list` — рецепты (story-video и др.) с параметрами.
2. `recipe_run {name: "story-video", params: {story, scenes, shot, style}}` — служба пишет сценарий, генерирует ролики сцен, музыку и речь; проект собирается сам (клипы по сценам, звук на дорожках). Долго: минуты на сцену.
3. Доработка как обычный монтаж: титры, переходы (1–2), цвет одним блоком на все клипы, музыка тише под речь.
4. Проверка: `frame_check` по одному кадру каждой сцены — герой одинаковый, нет артефактов; плохую сцену — перегенерировать графом в панели «Граф».

Модели генерации (картинки, видео, музыка, речь) — из настроек «Модели»; в нодах графа с пустым полем «Модель» подставляются они же.
