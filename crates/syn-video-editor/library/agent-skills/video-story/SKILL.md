# Мультфильм / видеоистория: порядок работы

Загрузи навыки: `screenplay` (сюжет и раскадровка), `minimax-h3` (промпт видео), `drama3` (озвучка), `qwen-image` (эталоны). Видео — только MiniMax-H3 Ref2VA; LTX — только по прямой просьбе (навык `ltx`).

## Главный способ: речь заранее, H3 — губы, шумы и музыка
1. **Сценарий и диалоги — первым делом, до любой генерации** (навык `screenplay`, раздел «Документ сценария»). Запиши два документа проекта:
   - `doc.write {name: "сценарий", text}` — **подробный** сценарий по шаблону из навыка `screenplay`: логлайн, герои (внешность, характер, голос, дуга), локации, структура (завязка, препятствия, поворот, кульминация, развязка) и **каждая сцена отдельным разделом** — место и время, задача сцены, план и камера, действие по битам, эмоции, звук, длительность, реплики с говорящими. Одна строка на сцену — не сценарий.
   - `doc.write {name: "диалоги", text}` — все реплики по сценам: сцена, говорящий, реплика по-русски с буквой ё, указания игры в [скобках] для Drama 3. Каждая озвученная реплика (`voice.say` с `scene`) сама дописывается в таблицу «Озвучка» этого документа.
   Перескажи пользователю сюжет в 3–5 предложениях. Документы пользователь видит в медиатеке и может править — **перед каждой сценой перечитывай** `doc.read {name: "сценарий"}` и `doc.read {name: "диалоги"}` и работай по исправленному тексту.
2. **Эталоны** (навык `qwen-image`): каждый герой во весь рост и каждая локация пустая — `recipe_run {name: "ref-image", open: false, label: "Эталон: <герой или локация>", asset: "<герой или локация>", params: {prompt, style}}` по одному; **`asset` обязателен** — имя героя или локации (без него файлы называются одинаково); путь из ответа запомни (это `<Picture k>`).
3. **Голоса героев** (навык `drama3`): `voice.cast {name, text}` — проба 8–15 с характерной речи с описанием голоса в [скобках] после первой фразы. Голос должен подходить герою (размер, возраст, характер). Сообщи пользователю, какие голоса получились (файлы в медиатеке).
4. **Сцена за сценой — обязательный порядок (его проверяет код).** Озвучка, план и съёмка сцены N+1 отказывают, пока сцена N не снята. Все сцены разом — только если пользователь прямо попросил: `story.mode {all_at_once: true}`. Где ты — `story.status`. Для каждой сцены по порядку:
   1. перечитай «сценарий» и «диалоги» (`doc.read`);
   2. **реплики сцены**: `voice.say {text, voice: "<герой>", scene: "<N>"}` на каждую (в тексте — слова; молчание — это пауза в сцене, а не реплика); сомнительные распознай (`media_transcribe`), не совпало — другой `seed`;
   3. **план сцены**: `scene.plan {scene: N, title, action_seconds: <сколько нужно действию по сценарию>, lines: [{file, speaker}, …] по порядку}`. Длина сцены = большее из действия и речи; сцена без речи — `lines` пустой, длина по действию. Сцена длиннее ролика H3 (18 с) делится на ролики **в тишине** — между репликами или в паузе внутри длинной фразы (запись режется по паузе, не переозвучивается). Ответ — ролики с окнами и дорожками говорящих (по ролику) и общая дорожка речи сцены; план — в документе «раскадровка»;
   4. **съёмка сцены**: один `recipe_run {name: "ref-scenes", label: "Сцена <N> из <M>: <название>", asset: "Сцена <N>", params: {refs: [эталоны сцены…, дорожки роликов из плана…], storyboard: <по строке на ролик плана>, style: "", chain: true, lang: "Russian", width: 960, height: 544}}`. Строки роликов одной сцены — **без `[CUT]`** между собой (продолжение по латенту: тот же фон, свет, расстановка); каждая строка — свои `<Audio k>` (дорожки этого ролика, `fully_copy`) и реплики теми же словами; во второй и следующих — `continues seamlessly from the previous shot`;
   5. **звук сцены**: общую дорожку речи сцены (`сцена-<N>-речь.wav`) поставь на звуковую дорожку под ролики сцены целиком (`clip_add`), звук роликов H3 — тише (шумы и музыка); так на стыках роликов речь без швов;
   6. **проверка**: распознай речь ролика (совпадает с репликами), посмотри кадры (`frame_check`); не так — пересними эту сцену, затем — следующая.
5. **Все сцены разом** (только по просьбе, после `story.mode`): реплики всех сцен → `scene.plan` каждой → съёмка; между сценами разных локаций — `[CUT]`.
6. **Повтор сцены**: слабую сцену — снова её реплики (при нужде) и `ref-scenes` с одной строкой, `open: false`, затем заменить клип.
7. **Проверка**: распознай речь 2–3 сцен (должна совпасть с репликами), посмотри кадры (`frame_check`: герои те же, губы двигаются у говорящего). Слабую сцену переснять: `ref-scenes` с одной строкой, `open: false`, затем заменить клип.
8. **Монтаж**: `skill_run cinematic_montage` (название, титры, цвет, звук) и экспорт.

Шаблон строки сцены (одной строкой; постановка — навык `minimax-h3`, «Постановка»):
`subject_definitions: <Picture 1> is <герой A: кто, внешность>. <Picture 2> is <герой B>. <Picture 3> is <локация>. <Audio 1> is the exact dialogue track of <A>. <Audio 2> is the exact dialogue track of <B>. summary: [reference generation] + [audio reuse] <суть сцены одной фразой>. retention_analysis: <Picture 1>: fully_preserved - <A>'s appearance. <Picture 2>: fully_preserved - <B>'s appearance. <Picture 3>: fully_preserved - the location; the layout stays exactly as in the reference. <Audio 1>: fully_copy - <A>'s speech, copied exactly and lip-synced. <Audio 2>: fully_copy - <B>'s speech, copied exactly and lip-synced. detailed_description: <стиль>; static locked-off camera, the layout does not change. [Shot 1] <план>: <Picture 1> (S1) <где стоит, что делает>; <Picture 2> (S2) <где стоит>, already in frame from the first frame. The characters face each other and never look at the camera. (S1) <действие без речи, взгляд на B>. (S1): <d>[Russian] <реплика A></d> Then (S2) turns to face <A> <действие без речи>. (S2): <d>[Russian] <реплика B></d> Each character moves the mouth only while their own audio is audible; otherwise the mouth stays closed. All speech comes only from the audio tracks; outside them nobody speaks, hums or makes vocal sounds. overall_soundscape: <шумы места и действий>. non_diegetic_music: <музыка или N/A>.`

## Быстрый способ без озвучки заранее
`recipe_run story-video` — всё одной командой (эталоны, план, сцены), но речь H3 придумывает сам: возможны акцент и чужие слова. Брать для роликов без важных реплик.

Модели генерации при пустом `model` / `image_model` берутся из настроек «Модели». Drama 3 и H3 вместе в видеокарту не помещаются — сначала вся озвучка (шаги 3–5), потом съёмка.
