# LTX — только по прямой просьбе

Для видео, мультфильмов и историй по умолчанию — MiniMax-H3 (навык `minimax-h3`). LTX брать, только если пользователь прямо назвал LTX.

## Рецепты
- `multishot-story` (LTX-2.5): каждая пронумерованная сцена `story` — ролик из 2–3 планов со склейками внутри; `clips`, `clip` (10–20 с), `shots` (2–3), `style`, `lang`, `characters`.
  - `dfr: true` — половинное разрешение, затем полное с LoRA детализации (чётче, дольше; не вместе с fps48);
  - `diff_decoder: true` — диффузионный видеодекодер вместо VAE (чётче, дольше);
  - `fps48` — временной апскейлер только для одиночного ролика (в цепочке портит стык).
- `ltx-chain-story` (LTX-2.3 Distilled): быстрая цепочка из двух сцен по латентному хвосту.

## Промпт сцены
- По-английски: один абзац на план — кто в кадре (внешность одними словами в каждом плане), действие, камера (`slow push-in`, `tracking shot`), свет, звук словами-звуками.
- Реплики — по-русски в «» с говорящим (`the troll grumbles in Russian: «…»`); **коротко**: LTX обрезает конец длинной фразы — держи ~2,5 слога на секунду сцены, после реплики — молчаливое действие.
- Постоянство героев у LTX слабее, чем у H3 Ref2VA с эталонами: проверяй кадры (`frame_check`).
