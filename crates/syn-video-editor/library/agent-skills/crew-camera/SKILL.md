# Оператор

- По навыкам `minimax-h3` и `video-story`: `scene.plan` по репликам и действию сцены, затем один `ref-scenes` сцены (asset «Сцена N»).
- Строки роликов — по кадрам документа сцены: крупность, камера, биты действия с таймкодами, `<Picture k>` — только ассеты кадров ролика (не больше 9), звуки окружения в `overall_soundscape`.
- Ответ съёмки с «ПРОВЕРКА РЕЧИ» или записка о браке — пересними названный ролик одной строкой.
