# Курьер (syncourier)

**Связь с компьютером через мессенджеры: уведомления и разговор с Claude Code из WhatsApp и Telegram — текстом, голосом, файлами.**

[English](README.md)

</div>

Курьер — служба synshell. Она привязывается к WhatsApp как связанное устройство (как WhatsApp Web) и слушает только
ваш чат **«Сообщения себе»**. Всё, что вы туда пишете, получает Claude Code — свой сеанс Курьера `courier`. Его
ответы, уведомления системы и события других сеансов Claude приходят туда же. Второй канал — **Telegram**: ваш
личный бот. Если подключены оба, ответы и уведомления идут туда, откуда вы писали последним. Почта — следующим каналом.

## Подключение

1. Значок **Курьер** на верхней панели (облачко сообщения) → **Подключить**. То же — в **Параметры → Курьер** или
   в терминале: `syncourier link` (QR-код символами).
2. На телефоне: WhatsApp → **Настройки → Связанные устройства → Привязка устройства**, навести камеру на QR-код.
3. Написать в «Сообщения себе» `/help`.

### Telegram

1. В Telegram откройте **@BotFather** → `/newbot`, придумайте имя и адрес бота — он пришлёт токен вида `123456789:AA…`.
2. **Параметры → Курьер → Telegram**: вставьте токен → **Подключить** (или `syncourier telegram-token ТОКЕН`).
3. Отсканируйте появившийся QR-код камерой телефона — откроется ваш бот; нажмите **Старт**. Бот запомнит ваш чат
   и больше никому не отвечает.

Адрес бота виден всем (уникальное имя в Telegram), но бот привязывается одноразовым кодом из QR и после этого слушает только ваш чат; чужим он не отвечает вовсе. Адрес лучше взять неочевидный (`имя_k7f3q_bot`). Команды, голос и файлы — те же, что в WhatsApp (у бота есть меню команд). Пределы Telegram для ботов: принять файл —
до 20 МБ, отправить — до 50 МБ. Токен и привязка хранятся в `~/.local/share/syncourier/telegram.json` (только для
владельца); «Отключить» забывает и то, и другое.

Служба запускается вместе с сеансом (`systemctl --user enable --now syncourier`). Сессия WhatsApp хранится в
`~/.local/share/syncourier/` (только для владельца); «Отключить» в окне Курьера выходит из учётной записи и стирает её.

## Разговор

Просто пишите — отвечает Claude Code. Он работает на этой машине так же, как ваши сеансы в терминале: файлы, команды,
система. Разговор продолжается и после перезапуска службы.

| Команда | Что делает |
|---|---|
| `/to ИМЯ текст` | передать сообщение живому сеансу Claude (`hexspire-b0`, `synshell-06`…); его ответ придёт сюда |
| `/sessions` | живые сеансы Claude: имя, занят/свободен, папка |
| `/new [ПАПКА]` | новый разговор (можно в другой папке) |
| `/stop` | прервать текущий ответ (разговор сохраняется) |
| `/status` | состояние каналов, Claude и режим уведомлений |
| `/notify claude\|away\|all` | какие уведомления системы присылать |
| `/help` | подсказка |

## Голос и файлы

- **Голосовые** распознаются службой нейросетей synaptix; распознанный текст уходит Claude (обратно вам не пересылается — расшифровка и так видна под голосовым).
- **Ответы голосом:** на голосовые и короткие разговорные ответы Claude иногда отвечает голосовым (синтез synaptix);
  код, ссылки и длинное — текстом.
- **Фото, видео, документы, аудио** сохраняются в папке загрузок (`~/Downloads/Курьер/`); Claude получает путь и вашу подпись —
  «что на фото?», «разбери этот PDF».
- **Файлы от Claude:** попросите «пришли снимок экрана», «пришли отчёт» — он отправит файлом.

## Уведомления

**Параметры → Курьер → Уведомления:**

- **Уведомления системы** (из любых программ): *не пересылать* · *когда меня нет* · *все*.
- **События Claude Code** (сеанс закончил ход, ждёт ответа или разрешения, зовёт вас): *когда меня нет* (по умолчанию) ·
  *всегда* · *никогда*.
- **«Меня нет»** — экран заблокирован или N минут (5 по умолчанию) без клавиатуры и мыши.
- **События Claude — от сеансов** — маски через запятую: `*` — любые символы, `!` — исключить, последнее совпадение
  побеждает. `!hexspire-*, hexspire-b0` — от всех, но из hexspire только от b0; `hexspire-b0, synshell-*` — только эти.
- **Не пересылать от программ** — список имён через запятую.

Если сеанс за ход сам написал вам (`syncourier notify/send/say`), итог этого хода хук не присылает — без дублей.

События Claude приходят через хуки Claude Code (`Stop`, `Notification` → `syncourier hook`) и через
`claude-call-user`.

## Командная строка

```text
syncourier status                    состояние (JSON)
syncourier link | unlink [telegram]  привязать (QR в терминале) / отвязать WhatsApp или Telegram
syncourier telegram-token ТОКЕН      бот Telegram: токен от @BotFather, дальше — QR-код в окне Курьера
syncourier notify ТЕКСТ [--title З] [--source claude]
                                     уведомление в мессенджер (source claude — по правилам событий Claude)
syncourier send ФАЙЛ [ПОДПИСЬ] [--voice | --file]
                                     отправить файл: картинка, видео, аудио (--voice — как голосовое), документ;
                                     --file — документом, без пережатия (PNG/WebP с прозрачностью и картинки > 10 МБ — сами)
syncourier say ТЕКСТ                 сказать голосом (синтез synaptix → голосовое)
syncourier ask ТЕКСТ                 сообщение как от вас (проверка без телефона)
syncourier hook                      для хуков Claude Code (JSON события на входе)
syncourier reload                    перечитать настройки
```

## Настройки

`~/.config/synshell/courier.toml` (или `~/.config/syndesktop/courier.toml`), правятся в Параметрах:

```toml
[whatsapp]
enabled = true

[telegram]
enabled = true                   # токен — в ~/.local/share/syncourier/telegram.json

[claude]
enabled = true
name = "courier"                 # имя сеанса для SendMessage других сеансов
cwd = "~"                        # рабочая папка
model = ""                       # opus | sonnet | haiku | полное имя; пусто — по умолчанию
permission_mode = "bypassPermissions"  # как у ваших сеансов — тогда они пишут друг другу

[notify]
mode = "claude"                  # claude | away | all — уведомления системы
claude = "away"                  # away | always | never — события Claude Code
away_minutes = 5
exclude = []                     # программы, которые не пересылать
```

## Безопасность

- Курьер реагирует **только** на чат «Сообщения себе» вашей учётной записи; остальные чаты не читаются.
- Кто получил доступ к вашему WhatsApp, тот может управлять компьютером через Claude. Держите телефон под
  блокировкой; при утере — «Связанные устройства → выйти» на телефоне или «Отключить» в Курьере.
- Библиотека WhatsApp неофициальная (whatsapp-rust, протокол WhatsApp Web); для чата с самим собой риск блокировки
  минимальный, но он есть.

## Устройство

`crates/syn-courier`: библиотека — протокол сокета `$XDG_RUNTIME_DIR/syncourier.sock` и настройки (её используют
апплет оболочки и Параметры), бинарник `syncourier` — служба и командная строка. Каналы — `wa.rs` (WhatsApp),
сеанс Claude — `claude.rs` (`claude -p` со `stream-json`, `--resume`), команды — `router.rs`, уведомления
D-Bus — `notify.rs`, хуки — `hook.rs`, вложения и голос — `media.rs`.
