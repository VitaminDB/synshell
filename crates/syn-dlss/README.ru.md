# syn-dlss

**DLSS 5 рабочего стола synshell — нейрорендеринг NVIDIA для Linux-игр, игр под Wine и видеоплеера: одно окно, чтобы включить его, настроить картинку и управлять помощником NGX.**

[English](README.md) · [Сайт](https://alexeyev.dev/ru/synshell/syn-dlss/)

</div>

syn-dlss — окно пакета `syn-wine-dlss5`, форка [DLSS5VKLayer](https://github.com/bmitch87/DLSS5VKLayer), который лежит в [`crates/syn-wine/dlss5`](../syn-wine/README.ru.md#dlss-5-dlss5). Vulkan-слой `VK_LAYER_NV_dlssnr` (64 и 32 бит) отдаёт кадры игры помощнику `dlssnr_helper.exe`, который работает под [syn-wine](../syn-wine/README.ru.md) и грузит NVIDIA NGX и модель DLSS 5; обработанный кадр возвращается игре. syn-dlss заменяет Qt-окно форка.

## Возможности

- **Главное** — нейрорендеринг вкл/выкл, стиль («Обычный», «Естественный» — бережнее к лицам, «Кинематографичный» — с плёночным тоном), точность оценки движения («Быстро», «Баланс», «Максимум»), сила эффекта и резкость (действуют сразу), шторка «до/после» в кадре.
- **Где работает** — «Игры syn-wine»: слой во всех программах syn-wine без переменной, с их следующего запуска; игры Steam: строка параметров запуска `VKLayer_DLSS5=1 %command%` для копирования; [видеоплеер](../syn-video-player/README.ru.md): кнопка «Фильтры» в его шапке, со своим видеопрофилем.
- **Настройки игры** — слой сообщает, какая игра запущена; «Сохранить для игры» оставляет ей свои настройки, «Забыть» возвращает на общие. Именованные профили — в `~/.config/dlssnr/profiles`.
- **Все настройки** — вкладки тонкой настройки: «Рендеринг» (пресет, интенсивность, локальная структура и тон, кожа, проходы, разрешение модели вплоть до суперсэмплинга), «Качество» (векторы движения по оптическому потоку GPU, HDR-вход, 16-битные промежуточные кадры), «Композиция» (сила деталей и цвета, предел цвета, защита светлых, как применяется ответ, белая точка), «Проверка» (сравнение рядом и шторкой, заморозка кадра, отладочные виды, клавиша переключения, снимки пар кадров до/после), «Помощник» (среда запуска, пауза пересборки, журнал, сброс).
- **Состояние помощника** — запуск, остановка и перезапуск; время модели на кадр, передача туда и обратно, видеопамять и функции NGX. Когда нейросети synaptixd занимают видеопамять, кнопка «Освободить» просит synaptixd их выгрузить.
- **Импорт модели** — модель `nvngx_dlssnr.dll` — проприетарный файл NVIDIA, в пакет она не входит: «Импортировать…» берёт каталог или файл (вместе с `nvngx.dll`, `nvapi64.dll`, `sl.*.dll` и лицензиями, если есть), «Найти на диске» ищет её в играх Steam и загрузках.
- **Окно компьютера** — свой заголовок, тема рабочего стола применяется на лету; 14 языков.

## Установка

В AUR `syn-wine-dlss5` не публикуется — собирается из репозитория synshell (x86_64, NVIDIA):

```sh
cd crates/syn-wine/dlss5/packaging
makepkg -si
```

Зависит от `syn-wine`, `nvidia-utils`, `vulkan-icd-loader`, `pciutils`; необязательно `lib32-vulkan-icd-loader` — для 32-битных Vulkan-игр. DXVK — из syn-wine (`/usr/share/dxvk`), DXVK-NVAPI — в пакете, ядро NGX — из драйвера NVIDIA. **Только окно, из исходников:** `cargo build --release -p syn-dlss`.

## Использование

Игре нужны кадры Vulkan: для Direct3D 8–11 — DXVK (в Proton он есть; в syn-wine — `setup-dxvk install`).

```sh
syn-dlss                          # окно
dlssnr-helper start               # запустить помощник (слой запускает его и сам; DLSSNR_AUTOSTART=0 — выкл)
dlssnr-helper status | stop | doctor
dlssnr-helper import-binaries КАТАЛОГ  # импорт nvngx_dlssnr.dll и сопутствующих DLL
VKLayer_DLSS5=1 игра              # слой в Linux-игре; в Steam: VKLayer_DLSS5=1 %command%
syn-dlss --screenshot shot.png --size 760x860 --tab quality
                                  # снимок окна (вкладки: rendering, quality, composition, inspect, helper)
```
